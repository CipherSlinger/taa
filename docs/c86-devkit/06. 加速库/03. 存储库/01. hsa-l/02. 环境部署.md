# 部署软件包

用户可直接从[Github ISA-L社区仓库](https://github.com/intel/isa-l)拉取最新代码，按照社区[README](https://github.com/intel/isa-l/blob/master/README.md)说明的方式，编译安装后使用。

## 参考部署方式

```bash
# 基础编译
./autogen.sh
./configure
make  # 编译的库在 ./libs 目录下

# 单元测试
make test
make check

# 安装
sudo make install
```

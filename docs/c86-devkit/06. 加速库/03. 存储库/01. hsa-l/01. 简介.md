# 基本信息

HSA-L是基于Intel ISA-L开发的，针对存储场景中常用算法的加速库。

当前HSA-L针对Hygon平台的优化方案**已经合入到Github ISA-L社区**。用户可以方便地从[Github ISA-L社区仓库](https://github.com/intel/isa-l)直接拉取使用。

当前已合入的优化主要包括：

- Erasure Code模块：
  - encode/decode接口AVX2实现方案的指令优化
  - update接口在Hygon特定平台上的指令集选取优化
- CRC模块：
  - crc32\_iscsi标准中，AVX+PCLMULQDQ实现方案的中、短数据计算方案的fastpath和指令优化
  - crc32\_iscsi标准中，AVX512+VPCLMULQDQ实现方案的短数据计算方案的fashtpath和指令优化

HSA-L优化方案保证ISA-L能够充分发挥Hygon处理器特性，在存储场景下达到理想的性能水平。

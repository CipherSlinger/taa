# 使用 Hygon 优化的 HCEPH 加速库

为启用 Hygon 提供的高性能 Ceph 优化库（HCEPH），请按以下步骤操作：

---

1. **确保 Ceph 环境可用**

   系统中需已正确部署并配置 Ceph 客户端或服务端环境（如 `ceph-common` 已安装，且可正常执行 `ceph`, `rados`, `rbd` 等命令）。

2. **安装 Hygon 提供的 `hceph` 安装包**

   通过 RPM、DEB 或其他方式安装 Hygon 定制优化的 `hceph` 软件包（通常包含优化后的 `libceph-common.so` 等核心库）。

3. **设置环境变量以加载优化库**

   通过 `LD_PRELOAD` 强制优先加载 Hygon 优化版本的 Ceph 公共库：

```bash
export LD_PRELOAD="{PATH}/libceph-common.so"
```

4. **执行ceph对应的应用程序即可使用优化后的hceph**

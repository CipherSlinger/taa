# 海光平台优化版 libhc 动态库说明

## 1. 背景说明

为充分发挥海光平台性能，libhc 借鉴并集成社区 Glibc 中针对海光平台的优化方案，构建了独立的动态库 `libh4c_avx512.so` , `libh4c.so` 和 `libh3c.so`。该动态库为完全独立的 `.so` 文件，无任何外部依赖，具备优秀的可移植性与兼容性，不会破坏系统原有 glibc。

## 2. 核心优化特性

### 2.1 AVX2 向量指令优化

针对 `memcmp`、`memcpy` 等核心内存操作函数进行 AVX2 向量指令优化，显著提升函数执行效率，尤其适配大数据量处理场景的性能需求。

### 2.2 NT memcpy 优化

引入非临时（Non-Temporal）存储技术，有效降低缓存污染问题；同时结合海光平台硬件特性，合理设置 NT Threshold（门限值），确保 `memcpy` 操作在海光平台达到最优性能。

### 2.3 NT memset 优化

在大尺寸内存初始化场景下，通过 Non-Temporal 指令提升内存带宽利用率，相比原生实现显著提升 `memset` 操作的性能。

### 2.4 strcmp 小字节场景优化

针对 `strcmp` 函数的小字节比较场景进行专项优化，提升小数据量字符串比较的执行效率。

### 2.5 AVX512 向量指令优化

针对支持 AVX-512 特性的硬件平台进行性能适配，获得最优执行性能。

### 2.6 大块拷贝 NT threshold 优化

针对大块内存拷贝场景优化 non-temporal copy 触发阈值，使 `memcpy` / `memmove` 在合适的数据规模下更早选择 non-temporal copy 路径，减少 cache 污染，提升大块拷贝场景下的吞吐性能。

### 2.7 TZCNT 优化字符串性能

针对字符串函数位扫描热点路径进行优化，使用 TZCNT 指令提升字符串查找、比较等场景下的执行效率，覆盖 `strlen` / `strcpy` / `strchr` / `strcmp` / `strncmp` / `memcmp` 等函数。

## 3. glibc 社区相关补丁与优化背景

作为 libhc 优化方案的补充背景，本节整理了 Glibc 社区中与海光平台适配、性能表现和兼容性改进相关的主要补丁与优化。这些内容既包括海光推动的改进，也包括对海光平台具有实际收益的社区通用优化。

这些优化主要集中在以下方向：

- CPU Vendor 识别与架构适配
- memcpy / memset NT（Non-Temporal）优化
- AVX512 适配
- 指令路径修复与稳定性增强
- 缓存与虚拟化环境适配

下表列出了目前已被 glibc 社区合入的主要优化版本与主线修复。

# 基本信息

libstdc++是C++标准库实现。其中libstdc++中随机数函数random\_device::\_M\_init在初始化检查RDRAND/RDSEED硬件指令的CPUID厂商白名单并未纳入海光，当业务代码调用随机函数 std::random\_device时，海光CPU无法走硬件随机通路，会降级回软件随机数生成逻辑到kernel实现,这就导致海光平台缺失硬件真随机支持，随机数生成的吞吐性能均无法实现最优。

海光针对C86平台内置的硬件随机数指令（RDRAND/RDSEED），完成了libstdc++中 std::random\_device的适配优化，优化后可以充分利用海光处理器内置的硬件随机数指令，降低随机数获取开销，并提升随机源质量。

当前海光C++优化方案**已经合入GCC国际社区**，用户可以直接从[GCC社区仓库](https://gcc.gnu.org/git/gcc.git)拉取包含该补丁的代码使用。

当前已合入的优化主要包括：

  - 在RDSEED/RDRAND的CPUID Vendor白名单中增加海光`HygonGenuine`签名
  - 显式`"rdseed"`、`"rdrand"`令牌在海光平台可以直接选择对应的硬件随机数源
  - 默认设备（`"default"`）在海光平台优先选择吞吐更高的RDRAND；需要更高熵种子的场景可通过`"rdseed"`显式指定

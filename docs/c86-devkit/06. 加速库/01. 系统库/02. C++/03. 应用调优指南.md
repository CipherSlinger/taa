# 应用调优指南

## 1. 使用指南

`std::random_device` 会根据CPUID自动探测处理器支持的随机数源。在海光平台且GCC已包含海光补丁时，无需修改源码即可使用硬件随机数指令。

### 1.1 使用方法

#### 方法 1：编译时指定动态库路径链接

编译阶段直接指定C++动态库路径和库文件，确保程序编译时关联目标库。

```bash
gcc -o 输出程序名 -L/opt/hygon/gcc/lib64 -llibstdc++.so 源文件.c
```

#### 方法 2：运行时通过环境变量强制加载

通过`LD_PRELOAD`环境变量，强制程序运行时优先加载指定动态库，无需重新编译程序。

```bash
export LD_PRELOAD=/opt/hygon/gcc/lib64/libstdc++.so
# 启动业务应用程序：
./app
```

### 1.2 验证动态库

通过以下命令验证动态库是否成功加载：

#### 方式 1：lsof命令

查看程序进程加载的库文件，路径是否符合预期：

```bash
lsof -p 程序进程ID | grep 库文件名
# 示例：lsof -p 12345 | grep libstdc++.so
```

#### 方式 2：pmap命令

查看进程的内存映射，确认库文件路径：

```bash
pmap 程序进程ID | grep 库文件名
# 示例：pmap 12345 | grep libstdc++.so
```

> 验证结果：若命令输出中显示目标库文件的路径（如 `/opt/hygon/gcc/lib64/libstdc++.so`），则说明库已成功被调用。

## 2. 性能优化案例

使用蒙特卡洛模拟场景对比使能hygon C++库优化前后的性能，预期使能hygonC++优化库后该场景的执行时间耗时更少，吞吐量指标更高。

```cpp
// 场景1: 蒙特卡洛模拟(量化金融/科学计算) - 欧式期权定价(BSM参数) + pi估计
// g++ -O3 -march=native mc_sim.cpp -o mc_sim
#include <cstdio>
#include <cstdint>
#include <cstdlib>
#include <cmath>
#include <random>
#include <chrono>

int main(int argc, char **argv)
{
    long long NP = argc > 1 ? atoll(argv[1]) : 2000000;   // pi 抽样数
    long long NO = argc > 2 ? atoll(argv[2]) : 1000000;   // 期权路径数

    std::random_device rd;
    std::uniform_real_distribution<double> U(0.0, 1.0);

    const auto t0 = std::chrono::steady_clock::now();

    long long inside = 0;
    for (long long i = 0; i < NP; ++i) {
        double x = U(rd), y = U(rd);
        inside += (x * x + y * y <= 1.0);
    }
    double pi = 4.0 * static_cast<double>(inside) / static_cast<double>(NP);

    const double S0 = 100.0, K = 100.0, r = 0.05, sigma = 0.2, T = 1.0;
    const double drift = (r - 0.5 * sigma * sigma) * T;
    const double vol = sigma * std::sqrt(T);
    double sum = 0.0;
    for (long long i = 0; i < NO; ++i) {
        double u1 = 1.0 - U(rd);          // (0,1], 避免 log(0)
        double u2 = U(rd);
        double z = std::sqrt(-2.0 * std::log(u1)) * std::cos(2.0 * M_PI * u2);
        double st = S0 * std::exp(drift + vol * z);
        double payoff = st - K;
        if (payoff < 0.0) payoff = 0.0;
        sum += payoff;
    }
    double price = std::exp(-r * T) * sum / static_cast<double>(NO);

    const auto t1 = std::chrono::steady_clock::now();
    double el = std::chrono::duration<double>(t1 - t0).count();

    long long calls = 4 * NP + 4 * NO;   // 每个 U(rd) 消耗2次rd() (2x32bit->53bit)
    printf("[MC] pi=%.5f (ref 3.14159) | call_price=%.4f (BSM ref 10.4506)\n", pi, price);
    printf("[MC] samples: pi=%lld + option=%lld -> rd_calls=%lld (4/sample)\n", NP, NO, calls);
    printf("[MC] elapsed=%.3f s  throughput=%.2f rd_calls/s  ns_per_call=%.1f\n",
           el, static_cast<double>(calls) / el, 1e9 * el / static_cast<double>(calls));
    return 0;
}

```

编译并运行：

```bash
g++ -O3 -march=native mc_sim.cpp -o mc_sim

# default system C++库
./mc_sim

# 使能hygon C++优化库
export LD_PRELOAD=/opt/hygon/gcc/lib64/libstdc++.so 
./mc_sim
```

## 3. 应用场景

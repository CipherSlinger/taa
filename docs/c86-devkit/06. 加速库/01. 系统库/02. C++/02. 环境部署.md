# 编译安装软件包

海光C++优化已合入GCC社区，用户可直接从[GCC社区仓库](https://gcc.gnu.org/git/gcc.git) 拉取最新代码，按照社区[编译说明](https://gcc.gnu.org/install/)编译安装后使用；也可以直接使用已包含该补丁的GCC发行版本。

## 获取源码

```bash
git clone git://gcc.gnu.org/git/gcc.git gcc-src
cd gcc-src
```

## 确认补丁已包含

```bash
git log --oneline --all --grep="Hygon x86 RNG instructions"
```

如果能够查询到提交 `0381c77496a780faf319d1d7acaebaa19b7413be`，说明当前源码已包含海光随机数优化补丁。

## 参考部署方式

以下以仅编译C/C++语言、安装到`/opt/hygon/gcc`为例：

```bash
# 安装编译依赖（以 openEuler/Kylin 为例，请按实际系统调整）
sudo dnf install -y gmp-devel mpfr-devel libmpc-devel isl-devel flex bison

# 配置
./configure --prefix=/opt/hygon/gcc \
            --enable-languages=c,c++ \
            --disable-multilib

# 编译（-j 参数根据 CPU 核数调整）
make -j$(nproc)

# 安装
sudo make install
```

## 使用新编译的libstdc++库

```bash
export LD_PRELOAD=/opt/hygon/gcc/lib64/libstdc++.so

```

# 国内社区

目前hygon已经将优化patch回合到对应的欧拉、龙蜥、腾讯云社区，用户可以参考上述方式按需下载编译适用；

```
1.国内社区-欧拉	
下载欧拉社区GCC代码（git clone https://gitcode.com/openeuler/gcc.git），检查hygon随机数补丁是否已经合入，hygon补丁在2026-09-07合入的，commit id: 05430f6be9f009340d81cb2d6bab54dceeebfee0.社区无版本号

2.国内社区-龙蜥
下载龙蜥社区GCC代码（git clone https://gitee.com/src-anolis-os/gcc.git），检查hygon随机数补丁是否已经合入，hygon补丁在2026-09-07合入的，commit id: b701a5342950fa42bcfe304df1909d00e2c91969.对应的龙蜥发布包版本号：12.3.0-21
	
3.国内社区-腾讯云	
下载腾讯云社区GCC代码（git clone https://gitee.com/OpenCloudOS/tgcc.git），检查hygon随机数补丁是否已经合入，hygon补丁在2026-07-17合入的，commit id: c8b28a26327246d5e9db67d4ac2061918fc0efc9.对应的腾讯云发布包版本号：12.3.1.8-6
```

# gzip

## 概述

gzip 是基于 DEFLATE 算法的标准无损数据压缩工具，广泛应用于 Linux/Unix 系统中。本优化版本以 **openEuler-24.03** 操作系统默认的 **gzip-1.12** 为基准，基于 **C86-4G, C86-4G/H** 进行深度性能优化。

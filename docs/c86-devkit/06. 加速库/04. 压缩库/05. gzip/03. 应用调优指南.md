# 环境准备

## 1. 下载测试数据集

使用 **Silesia 测试语料库**（压缩算法性能测试常用标准数据集）：

```bash
# 下载 Silesia 测试数据集
wget http://sun.aei.polsl.pl/~sdeor/corpus/silesia.zip

# 解压数据集到 silesia 目录
unzip silesia.zip -d silesia
```

## 2. 数据集打包

将解压后的 Silesia 数据集打包为 tar 格式（便于统一测试）：

```bash
# 进入数据集目录
cd silesia

# 打包为 tar 文件
tar -cf ../silesia.tar *

# 返回上级目录
cd ..
```

## 3. 性能测试

### 测试方法

采用 **单核性能基准测试**，使用 `numactl` 进行绑核，以消除 CPU 调度带来的性能抖动。

```bash
# 压缩测试
time numactl -C 11 ./gzip silesia.tar

# 解压测试
time numactl -C 11 ./gzip -d silesia.tar.gz
```

### 测试说明

- **测试数据集**：`silesia.tar`（约 200 MB）
- **绑核策略**：单核性能测试，`numactl -C 11` 固定 CPU 核心 11
- **衡量指标**：统计压缩和解压的**耗时**（秒/毫秒），以时间维度衡量性能差距
- **测试次数**：建议多次运行取平均值，以获得稳定结果

## 4. 兼容性测试

验证优化后的 gzip 数据格式与 OS 系统原生自带的 gzip 软件之间的**双向兼容性**。

### 测试用例 1：原生压缩 → 优化解压

```bash
# 使用 OS 自带的 gzip 压缩
gzip -k silesia.tar                     # 生成 silesia.tar.gz

# 使用优化后的 gzip 解压
./gzip -d silesia.tar.gz                # 还原为 silesia.tar

# 比对内容一致性
vimdiff ori/silesia.tar silesia.tar         # 一致则 PASS
```

### 测试用例 2：优化压缩 → 原生解压

```bash
# 使用优化后的 gzip 压缩
./gzip -k silesia.tar                   # 生成 silesia.tar.gz

# 使用 OS 自带的 gzip 解压
gzip -d silesia.tar.gz                  # 还原为 silesia.tar

# 比对内容一致性
vimdiff ori/silesia.tar silesia.tar         # 一致则 PASS
```

> **判定标准**：两种测试场景下，`vimdiff` 比对结果显示文件内容完全一致，即判定为兼容性 **PASS**。

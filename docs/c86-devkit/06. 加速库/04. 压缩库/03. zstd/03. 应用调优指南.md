# 使用 Hygon 优化的 zstd 加速库

为启用 Hygon 提供的高性能 zstd 优化库，请按以下步骤操作：

---

## 1. 设置环境变量以加载优化库

通过 `LD_PRELOAD` 强制优先加载 Hygon 优化版本的 zstd 公共库：

```bash
export LD_PRELOAD="/path/to/lib64/libzstd.so"
```

> **注意**: 将 `{PATH}` 替换为您实际的 Hygon 优化库路径。

## 2. 使用优化后的 zstd

执行 zstd 对应的应用程序即可使用优化后的 zstd。

# 使用 lzbench 对 zstd 进行性能测试

## 1. 环境准备

### 1.1 克隆代码仓库与下载测试数据集

首先克隆 lzbench 源码仓库，并下载 Silesia 测试语料库（压缩算法性能测试常用数据集）：

```bash
# 克隆 lzbench 仓库
git clone https://github.com/inikep/lzbench.git
cd lzbench
git reset --hard 613b271b2305d25cf153e77733681885be19d77f

# 下载 Silesia 测试数据集
wget http://sun.aei.polsl.pl/~sdeor/corpus/silesia.zip 

# 解压数据集到 silesia 目录
unzip silesia.zip -d silesia 
```

### 1.2 数据集打包

将解压后的 Silesia 数据集打包为 tar 格式（便于 lzbench 统一测试）：

```bash
# 进入数据集目录
cd silesia 

# 打包为 tar 文件
tar -cf ../silesia.tar *

# 返回上级目录
cd ..
```

## 3. 编译与测试流程

### 3.1 zstd 测试（静态库 / 动态库）

#### 3.1.1 静态库编译与测试

```bash
make -j32 DONT_BUILD_ZLIB_NG=1 USE_STATIC_ZSTD=1 OPT_LIB_PATH=/opt/hygon/lib64
# 测试 ZSTD 不同压缩级别（3/6）的性能
./lzbench -ezstd,3/zstd,6 -b64 silesia.tar 
```

#### 3.1.2 动态库编译与测试

```bash
make clean
make -j32 DONT_BUILD_ZLIB_NG=1 USE_SHARED_ZSTD=1 OPT_LIB_PATH=/opt/hygon/lib64
./lzbench -ezstd,3/zstd,6 -b64 silesia.tar 
```

## 参数说明

- `DONT_BUILD_ZLIB_NG=1`: 禁用 zlib-ng 构建，只构建原始 zstd
- `USE_STATIC_ZSTD=1`: 使用静态链接的 zstd 库
- `USE_SHARED_ZSTD=1`: 使用共享（动态链接）的 zstd 库
- `OPT_LIB_PATH`: 指定优化库的路径（例如 `/opt/hygon/lib64`）
- `-j32`: 使用 32 个并行任务进行编译
- `-ezlib,3`: 测试 zstd 压缩算法，使用压缩级别 3

## 注意事项

1. 确保 `/opt/hygon/lib64` 目录中存在相应的库文件（`libzstd.a` 或 `libzzstd.so`）
2. 如果使用共享库，请确保库文件在运行时能够被找到
3. 在使用动态库时，RPATH 会被设置为库所在目录，确保运行时可以找到库

# 背景

Zstd（发音为 “Zee-standard”）是由Facebook（现 Meta） 于 2016 年推出的无损数据压缩算法 / 库，核心由 Yann Collet 开发。它的设计目标是在压缩率和压缩 / 解压速度之间实现远超传统算法（如 zlib）的平衡，同时保持轻\>量、可扩展、跨平台的特性。
Zstd 并非单一算法，而是一套包含核心压缩逻辑、多级压缩策略、字典压缩（Dictionary Compression）等功能的完整压缩解决方案，遵循 BSD 开源许可证（商用友好，无开源绑定要求）。

# 优化

c86-devkit目前重点关注zstd level 1至level 5压缩流程，以及全level解压缩处理流程。主要从以下角度完成优化：

- AVX指令集扩展，实现更高效的数据复制
- 结合海光平台微架构特点的指令调整
- 搜索算法、搜索参数的调整
- 部分访存的简化
- 部分解压缩处理逻辑的调整

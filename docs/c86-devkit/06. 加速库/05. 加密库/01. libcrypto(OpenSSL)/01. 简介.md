# 背景

OpenSSL是一个针对包括传输层安全协议（TLS，旧称SSL）、数据报传输层安全协议(DTLS)、以及QUIC协议的，功能完备的商业级开源工具包。

协议的实现均基于一个完备的、也可以作为独立组件单独使用的通用加密库。此外，OpenSSL还包含一个符合FIPS标准验证的密码模块。

# 优化

c86-devkit目前针对OpenSSL提供的libcrypto.so加密库内特定加密算法进行Hgyon平台架构的优化，主要包括：

- MD5信息摘要算法。主要针对流程中部分指令和计算方式进行了调整。

为了更好的适配性，c86-devkit同时提供基于 OpenSSL 和 OpenSSL 3 两个版本的libcrypto动态库。

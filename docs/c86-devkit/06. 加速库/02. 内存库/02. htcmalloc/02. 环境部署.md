## 手动下载安装

可通过以下链接访问并下载所有发布版本的 htcmalloc 安装包：

🔗 安装包地址：[libs | 光合开发者社区](https://download.sourcefind.cn:65024/8/main/c86-devkit/latest/libs)

### 操作步骤

1. 访问上述地址，浏览具体文件并生成直接下载链接；
2. 通过 `wget -c package_url` 命令下载安装包（将 `package_url` 替换为实际生成的下载链接）；
3. 执行对应系统的安装命令完成安装：

## tar包安装命令

```bash
sudo tar -zvxf $package
```

**说明**：命令中的 `$package` 需替换为下载得到的安装包文件名（若安装包不在当前执行命令的目录下，需补充完整路径）。

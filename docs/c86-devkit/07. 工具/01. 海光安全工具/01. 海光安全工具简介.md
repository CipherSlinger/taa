# 海光安全工具简介

## 概述

海光安全工具简称hag，是`HYGON`对外提供的支持所有海光安全功能的应用程序。可以通过以下链接下载最新版本。

https://download.sourcefind.cn:65024/8/main/c86-devkit/latest/tools

## 命令使用方式

##### HAG命令输入方式为：./hag category command \[-options\]，示例：

```
cd /opt/hygon/bin/
./hag general check
```

##### HAG帮助信息获取方式


### HAG常用命令介绍

#### 1. 获取HAG的版本号

```
./hag general version
```

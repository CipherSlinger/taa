# Hygon C86 HPC Kit 环境部署

## 1.软硬件要求

**硬件要求：**

- Hygon C86-4G及以上

**软件要求：**

- GNU C Library (glibc) （\> 2.27）
- gcc（\>=4.8.x+）
- clang（\>=3.6.0）

*HMPI 使用 Open MPI 5.0.x 作为开发基础，因此支持该版本所支持的运行时系统。*

**已验证支持的操作系统包括：**
Ubuntu 18.04、Ubuntu 22.04、CentOS 8.5、SUGON OS 8.5、SUGON OS 8.9、Rocky Linux 9.5、Kylin V10，以及 Anolis OS 8.9（不支持 32 位操作系统）

## 2. 环境部署

c86-hpckit目录结构如下：

```bash
.
├── install.sh
├── payload/
│   ├── *.tar
└── script/
    ├── hpc-setenv.sh
    ├── hpc-unsetenv.sh
    ├── hpc-modulefiles-setup.sh
    └── uninstall.sh

```

### 2.1 获取软件包

获取软件包方式：

- 点击链接跳转：[光和开发者社区-c86-devkit](https://download.sourcefind.cn:65024/8/main/c86-devkit)

### 2.2 准备工作

在开始安装前，请确保以下条件已满足：

1. **权限要求**
   
   - 默认安装会安装至系统`/opt` 目录，请确保具备 root 或具备写入 `/opt` 目录的权限。
   - 支持自定义安装路径，安装完成后会在自定义安装路径下新建`hygon/`目录，请确保具备相应权限。

2. **注意事项**
   
   - 请检查系统中是否已有其他版本的 Hygon HPC 工具链或相关组件安装在 `/opt/hygon` 或其他路径，以避免路径冲突或环境变量覆盖。
   - 安装前建议备份已有组件或安装目录，以防覆盖导致原有环境不可用。
   - 确认系统依赖库版本符合要求（glibc ≥ 2.27、GCC 满足版本要求等），否则可能导致运行异常或软件包无法正常使用。

### 2.3 安装

#### 2.3.1 默认安装

进入根目录：

```bash
sudo bash ./install.sh
```

install.sh 会执行以下内容：

- 将payload中的包安装到 ‘/opt/hygon/’ 路径

#### 2.3.2 自定义路径安装

自定义安装支持 `--install-dir` 参数，用于指定安装目录。
或直接普通用户执行install脚本，在交互界面输入自定义安装路径。

```bash
bash install.sh --install-dir /path/to/install
```

### 2.4 设置环境变量

#### 2.3.1 setenv模式

安装完成后执行：

```bash
    source /path/to/hygon/hpc-setenv.sh
```

根据提示选择hcc或hgcc编译器 或：

```bash
    source /path/to/hygon/hpc-setenv.sh hcc
```

```bash
    source /path/to/hygon/hpc-setenv.sh hgcc
```

验证：

```bash
    gcc -v
    clang -v
    mpirun -V
```

去除环境变量：

```bash
    bash /path/to/hygon/hpc_unsetenv.sh
```

此脚本仅撤销 HPC Kit 添加的环境变量，不会影响系统默认 gcc/clang

#### 2.3.2 使用environment-modules

*为了更有力的支持多版本环境和模块的调试，软件包支持借助module命令模块化管理组件，请预先自行安装environment-modules*

软件包安装完成后执行：

```bash
    bash /path/to/hygon/modulefile-setup.sh
```

脚本将会：

- 自动创建 modulefiles 目录

- 根据已安装的组件生成对应模块文件

生成module文件以后，需要先让环境模块识别：

```bash
    module use /path/to/hygon/modulefiles
```

加载对应模块：

```bash
    module load hcc
    module load hgcc
```

卸载已加载模块：

```bash
    module unload hcc
    module unload hgcc
```

也可以使用下面命令查看已注册或可用的组件：

```bash
    module avail
```

卸载所有已加载的模块：

```bash
    module purge
```

模块加载后可验证：

```bash
    gcc -v
    clang -v
    mpicc -V
```

### 2.5 卸载

使用以下提供的卸载脚本可卸载掉已安装的软件包：

```bash
    sudo bash /path/to/hygon/uninstall.sh
```

`uninstall.sh` 会删除 `/path/to/hygon/` 下所有由本工具包安装的内容，请谨慎操作。

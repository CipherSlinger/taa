# C86-HPCKit 安装指南

## 1. 安装简介

### 1.1 简介和组件列表

C86-HPCKit 是面向高性能计算场景的统一开发与运行环境软件包，集成编译器、MPI、数学库等工具链组件，适用于 Hygon C86 平台的 HPC 开发与部署。

### 1.2 软硬件要求

#### 1.2.1 硬件要求

- Hygon C86-4G 及以上处理器。

#### 1.2.2 软件要求

- GNU C Library（glibc）大于 2.27。
- GCC 4.8.x 或更高版本。
- Clang 3.6.0 或更高版本。

HMPI 使用 Open MPI 5.0.x 作为开发基础，因此支持该版本所支持的运行时系统。

已验证支持的操作系统包括 Ubuntu 18.04、Ubuntu 22.04、CentOS 8.5、SUGON OS 8.5、SUGON OS 8.9、Rocky Linux 9.5、Kylin V10 以及 Anolis OS 8.9。不支持 32 位操作系统。

## 2. 安装前准备

### 2.1 获取软件包

从 [C86 DevKit 下载页面](https://download.sourcefind.cn:65024/8/main/c86-devkit)获取 C86-HPCKit 软件包。

C86-HPCKit 软件包的目录结构如下：

```text
.
├── install.sh
├── payload/
│   └── *.tar
└── script/
    ├── hpc-setenv.sh
    ├── hpc-unsetenv.sh
    ├── hpc-modulefiles-setup.sh
    └── uninstall.sh
```

### 2.2 准备工作

在开始安装前，请确保以下条件已满足。

#### 2.2.1 权限要求

- 默认安装会安装至系统 `/opt` 目录，请确保具备 root 权限或写入 `/opt` 目录的权限。
- 支持自定义安装路径。安装完成后会在自定义安装路径下新增 `hygon/` 目录，请确保具备相应权限。

#### 2.2.2 注意事项

- 请检查系统中是否已有其他版本的 Hygon HPC 工具链或相关组件安装在 `/opt/hygon` 或其他路径，以避免路径冲突或环境变量覆盖。
- 安装前建议备份已有组件或安装目录，以防覆盖导致原有环境不可用。
- 确认系统依赖库版本符合要求，例如 glibc 大于 2.27、GCC 满足版本要求，否则可能导致运行异常或软件包无法正常使用。

## 3. 安装卸载 C86-HPCKit

### 3.1 安装方式介绍

C86-HPCKit 支持默认路径安装和自定义路径安装。自定义路径可以通过 `--install-dir` 参数指定，也可以在执行安装脚本后根据交互提示输入。

### 3.2 安装 C86-HPCKit（非交互式）

#### 3.2.1 默认路径安装

进入软件包根目录，执行：

```bash
sudo bash ./install.sh
```

`install.sh` 会将 `payload/` 中的软件包安装到 `/opt/hygon/` 路径。

#### 3.2.2 自定义路径安装

自定义安装支持 `--install-dir` 参数，用于指定安装目录。

```bash
bash install.sh --install-dir /path/to/install
```

### 3.3 安装 C86-HPCKit（交互式）

普通用户可以直接执行安装脚本：

```bash
bash ./install.sh
```

根据交互界面的提示输入自定义安装路径。

### 3.4 设置环境变量

#### 3.4.1 setenv 模式

安装完成后执行：

```bash
source /path/to/hygon/hpc-setenv.sh
```

根据提示选择 HCC 或 HGCC 编译器，也可以直接执行：

```bash
source /path/to/hygon/hpc-setenv.sh hcc
```

或：

```bash
source /path/to/hygon/hpc-setenv.sh hgcc
```

执行以下命令进行验证：

```bash
gcc -v
clang -v
mpirun -v
```

执行以下命令去除 C86-HPCKit 设置的环境变量：

```bash
source /path/to/hygon/hpc-unsetenv.sh
```

> 注意：`hpc-unsetenv.sh` 必须使用 `source`（或 `.`）加载，不能使用 `bash` 执行。该脚本通过修改**当前 shell** 的环境变量来撤销 C86-HPCKit 的设置；用 `bash` 启动子 shell 执行时，修改只作用于子 shell，无法撤销当前 shell 的环境变量，且脚本会检测到非 source 方式并直接报错退出。

该脚本仅撤销 C86-HPCKit 添加的环境变量，不会影响系统默认的 GCC 或 Clang。

#### 3.4.2 使用 Environment Modules

为了更方便地支持多版本环境和模块切换测试，软件包支持借助 `module` 命令进行模块化管理。使用前请自行安装 `environment-modules`。

软件包安装完成后执行：

```bash
bash /path/to/hygon/hpc-modulefiles-setup.sh
```

该脚本将：

- 自动创建 `modulefiles` 目录。
- 根据已安装的组件生成对应模块文件。

生成模块文件后，使环境模块识别该目录：

```bash
module use /path/to/hygon/modulefiles
```

加载对应模块：

```bash
module load hcc
module load hgcc
```

卸载已加载模块：

```bash
module unload hcc
module unload hgcc
```

查看已注册或可用的组件：

```bash
module avail
```

卸载所有已加载的模块：

```bash
module purge
```

模块加载后，可以执行以下命令进行验证：

```bash
gcc -v
clang -v
mpicc -v
```

### 3.5 卸载

使用软件包提供的卸载脚本卸载已安装的软件包：

```bash
sudo bash /path/to/hygon/uninstall.sh
```

`uninstall.sh` 会删除 `/path/to/hygon/` 下由本工具包安装的内容，请谨慎操作。

### 3.6 升级 C86-HPCKit

C86-HPCKit 的 `install.sh` 为覆盖式安装，不提供原地增量升级，也不会在覆盖前清理旧版本残留的文件。因此升级方式取决于原有版本的安装路径：默认路径建议先卸载再安装，自定义路径建议安装到新路径使新旧版本共存。

#### 3.6.1 默认路径安装的升级

如果原版本使用默认路径安装至 `/opt/hygon/`，升级前需先卸载原有版本，再安装新版本。

卸载原有版本：

```bash
sudo bash /opt/hygon/uninstall.sh
```

安装新版本：

```bash
sudo bash ./install.sh
```

#### 3.6.2 自定义路径安装的升级

如果原版本使用自定义路径安装，无需卸载原版本，只需将新版本安装到其他路径即可：

```bash
bash install.sh --install-dir /path/to/new/install
```

新旧版本可共存，需要切换版本时，可通过 `source` 对应路径的 `hpc-setenv.sh`，或使用 Environment Modules 加载所需版本的模块（参见 3.4 设置环境变量）。

使用 setenv 模式切换版本时，需先去除旧版本设置的环境变量，再 `source` 新版本的 `hpc-setenv.sh`：

```bash
source /path/to/old/hygon/hpc-unsetenv.sh
source /path/to/new/hygon/hpc-setenv.sh
```

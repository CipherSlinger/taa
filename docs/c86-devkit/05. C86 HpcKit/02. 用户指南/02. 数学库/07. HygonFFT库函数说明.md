# 6. HygonFFT库函数说明

## 6.1 函数说明

HygonFFT（HML\_FFT）是面向海光 CPU 的快速傅里叶变换库。它对外提供 FFTW 兼容接口：应用继续包含 `<fftw3.h>`，调用 `fftw_*` 或 `fftwf_*` 函数，并链接 HygonFFT 发行包提供的 FFTW 兼容库。对发行包已覆盖且 ABI 匹配的接口，应用不需要改写 FFT 调用代码，运行时由 HygonFFT 兼容层接管实现。

HygonFFT 采用 FFTW 的“创建 Plan → 执行变换 → 销毁 Plan”模型。

> \[!IMPORTANT\]
> “FFTW 兼容”是有范围的接口兼容结论。目前参照标准 AMD-FFTW 的源码版本 FFTW-3.3.8 提供兼容接口。使用前必须核对目标发行包提供的精度、线程库和动态符号。

### 6.1.1 接入方式

- **接入**：包含 `<fftw3.h>`，链接 `-lfftw3`（单精度 `-lfftw3f`）。
- **多线程**：链接 OpenMP 线程库 `-lfftw3_omp`，通过 `fftw_plan_with_nthreads` 或环境变量 `HML_FFT_OMP_NUM_THREADS` 设置线程数。
- **闭源替换**：已有程序无需重新编译，用 `LD_LIBRARY_PATH` / `LD_PRELOAD` 覆盖原 FFTW 依赖即可。

编译（双精度）：

```bash
gcc fft_example.c -I<HML_ROOT>/include -L<HML_ROOT>/lib -lfftw3 -lm -o fft_example
```

闭源替换：

```bash
export LD_LIBRARY_PATH=<HML_ROOT>/lib:$LD_LIBRARY_PATH
export LD_PRELOAD=<HML_ROOT>/lib/libfftw3.so:$LD_PRELOAD   # 仅当搜索路径无法覆盖时
./program
```

> 静态链接 FFTW、或已将 FFTW 对象代码合入可执行文件的程序，动态替换不会生效，必须重新链接。

### 6.1.2 支持的变换类别

复数（C2C）、实数（R2C/C2R）、实数到实数（R2R），以及批量、Guru 布局。

| 类别 | 输入与输出 | 典型接口 |
|---|---|---|
| C2C | 复数到复数 | `fftw_plan_dft_*` |
| R2C | 实数到厄米对称复数频谱 | `fftw_plan_dft_r2c_*` |
| C2R | 厄米对称复数频谱到实数 | `fftw_plan_dft_c2r_*` |
| R2R | DCT、DST、DHT 和半复数变换 | `fftw_plan_r2r_*` |
| 批量与非连续布局 | 多批次、带步长或嵌入数组 | `fftw_plan_many_*` |
| 任意布局 | 独立描述变换维和批量维 | `fftw_plan_guru_*` |
| 多线程 | 一个 Plan 内部并行执行 | `fftw_init_threads`、`fftw_plan_with_nthreads` |

### 6.1.3 精度与库文件

| 精度 | 函数前缀 | 实数类型 | 复数类型 | 顺序库 | OpenMP 线程库 |
|---|---|---|---|---|---|
| 双精度 | `fftw_` | `double` | `fftw_complex` | `libfftw3` | `libfftw3_omp` |
| 单精度 | `fftwf_` | `float` | `fftwf_complex` | `libfftw3f` | `libfftw3f_omp` |

> \[!IMPORTANT\]
> HygonFFT 只提供双精度和单精度接口，不支持长双精度（long double，`fftwl_` / `fftwl_complex` / `-lfftw3l`）和 Quad 精度（float128，`fftwq_` / `fftwq_complex` / `-lfftw3q`）。

不同精度的 Plan 和数组类型不能混用。

### 6.1.4 典型调用流程

典型流程：分配内存 → 创建 Plan → 填充输入 → `fftw_execute` 执行 → 销毁 Plan、释放内存。

用户通常按以下顺序调用：

1. 使用 `fftw_malloc`、`fftw_alloc_real` 或 `fftw_alloc_complex` 分配对齐内存。
2. 选择与数据类型和布局匹配的规划函数创建 `fftw_plan`。
3. 检查 Plan 是否为 `NULL`，然后填充实际输入数据。
4. 调用 `fftw_execute` 或类型专用执行函数。
5. 调用 `fftw_destroy_plan`，再使用 `fftw_free` 释放数组。

最小的一维复数 DFT 示例：

```c
#include <fftw3.h>
#include <stdio.h>

#define N 8

int main(void)
{
    fftw_complex *in  = fftw_alloc_complex(N);
    fftw_complex *out = fftw_alloc_complex(N);
    fftw_plan plan = fftw_plan_dft_1d(N, in, out, FFTW_FORWARD, FFTW_ESTIMATE);

    for (int i = 0; i < N; ++i) { in[i][0] = 0.0; in[i][1] = 0.0; }
    in[0][0] = 1.0;

    fftw_execute(plan);

    for (int k = 0; k < N; ++k)
        printf("%d: %+.3f %+.3fi\n", k, out[k][0], out[k][1]);

    fftw_destroy_plan(plan);
    fftw_free(in);
    fftw_free(out);
    return 0;
}
```

## 6.2 接口规范说明

HygonFFT 采用与 FFTW 一致的接口规范：

- **命名前缀**：双精度 `fftw_`，单精度 `fftwf_`。
- **变换模型**：先创建 Plan，再执行变换；Plan 可重复执行。
- **未归一化约定**：变换均未归一化，正向与反向连续执行后数据乘以变换长度。
- **接口层次**：基本接口、高级接口、Guru 接口。
- **数据布局**：C 接口行主序，最后一个维度变化最快。
- **内存对齐**：推荐使用 `fftw_malloc` / `fftw_alloc_real` / `fftw_alloc_complex` 分配。在海光平台上，64 字节对齐可获得最佳性能；FFTW 内置的这些分配接口只提供基本的对齐保证，应用若需要更高对齐应自行分配对齐内存。

## 6.3 数据结构

### 6.3.1 数据类型

双精度复数类型通常定义为两个连续的 `double`：

```c
typedef double fftw_complex[2];
```

元素 `[0]` 为实部，元素 `[1]` 为虚部。若在 `<fftw3.h>` 前包含 C99 `<complex.h>`，头文件可以使用兼容的原生复数表示；跨语言或使用 `std::complex<double>` 时，调用者仍需确认目标编译器的布局和 ABI。

`fftw_plan` 是不透明句柄。调用者只能通过 FFTW 公共函数创建、执行、复制或销毁 Plan，不能读取或修改其内部成员。

Guru 接口使用以下维度结构：

```c
typedef struct {
    int n;
    int is;
    int os;
} fftw_iodim;

typedef struct {
    ptrdiff_t n;
    ptrdiff_t is;
    ptrdiff_t os;
} fftw_iodim64;
```

`n` 是维度长度，`is` 和 `os` 分别是输入与输出步长。步长按对应数组的元素计数，不按字节计数。

### 6.3.2 Plan 生命周期

Plan 记录变换类别、维度、布局、方向、线程数及数组对齐类别。其生命周期规则如下：

- 创建失败返回 `NULL`，执行前必须检查。
- `FFTW_MEASURE`、`FFTW_PATIENT` 和 `FFTW_EXHAUSTIVE` 在规划期间可能覆盖输入或输出数组；安全做法是先创建 Plan，再填充实际输入。
- `fftw_execute(plan)` 使用创建 Plan 时绑定的数组。
- 新数组执行函数可以替换数组地址，但不能改变尺寸、步长、批量结构、原位/非原位关系或对齐类别。
- `fftw_destroy_plan` 只释放 Plan，不释放用户数组。
- `fftw_cleanup` 和 `fftw_cleanup_threads` 会清理全局状态；调用后不得继续使用此前创建的 Plan。

### 6.3.3 方向、归一化和规划标志

`FFTW_FORWARD` 的值为 `-1`，对应负指数；`FFTW_BACKWARD` 的值为 `+1`，对应正指数。R2C 固定为正向变换，C2R 固定为反向变换，因此相应规划函数没有 `sign` 参数。

FFTW 兼容接口不自动归一化。长度为 `n` 的一维变换正向后接反向，结果为原输入的 `n` 倍；多维 C2C/R2C/C2R 的缩放因子为各维长度的乘积。

常用规划标志如下。

| 标志 | 作用 | 使用建议 |
|---|---|---|
| `FFTW_ESTIMATE` | 不运行候选变换，快速建立 Plan | 规划次数多或只执行少量变换时优先 |
| `FFTW_MEASURE` | 实测候选方案 | 同一 Plan 重复执行较多次时使用 |
| `FFTW_PATIENT` | 搜索更多候选方案 | 允许更长初始化时间时使用 |
| `FFTW_EXHAUSTIVE` | 执行更全面的搜索 | 仅在规划成本可接受时使用 |
| `FFTW_DESTROY_INPUT` | 允许执行过程改写输入 | 输入无需保留时使用 |
| `FFTW_PRESERVE_INPUT` | 要求保留输入 | 某些布局可能无法据此生成 Plan |
| `FFTW_UNALIGNED` | 不要求特殊对齐 | 可提高地址兼容性，但可能降低 SIMD 性能 |

多个独立标志使用按位或运算组合。

### 6.3.4 实数 DFT 的压缩与原位布局

长度为 `n` 的实数输入，其 R2C 输出只保存非冗余频谱：

$$
N\_{\\mathrm{complex}}
\= \\left\\lfloor \\frac{n}{2} \\right\\rfloor + 1.
$$

`out[0]` 为纯实数；当 `n` 为偶数时，`out[n/2]` 也为纯实数。

多维实数数组只压缩最后一个维度。若逻辑实数尺寸为：

$$
n\_0 \\times \\cdots \\times n\_{d-1},
$$

则复数输出尺寸为：

$$
n\_0 \\times \\cdots \\times
\\left(
\\left\\lfloor \\frac{n\_{d-1}}{2} \\right\\rfloor + 1
\\right).
$$

原位 R2C/C2R 使用同一内存块表示实数和复数。实数数组最后一维的物理长度至少为：

$$
2\\left(
\\left\\lfloor \\frac{n\_{d-1}}{2} \\right\\rfloor + 1
\\right)
$$

个实数元素。创建 Plan 时仍传递逻辑尺寸，不传递填充后的物理尺寸。

### 6.3.5 R2R 变换类型

`fftw_r2r_kind` 指定实数到实数变换。表中的逻辑长度 `N` 是某类型与其逆类型连续执行后的缩放因子。

| 常量 | 变换 | 逆类型 | 逻辑长度 `N` |
|---|---|---|---|
| `FFTW_R2HC` | 实数 DFT 到半复数格式 | `FFTW_HC2R` | `n` |
| `FFTW_HC2R` | 半复数格式到实数 | `FFTW_R2HC` | `n` |
| `FFTW_DHT` | 离散哈特莱变换 | 自身 | `n` |
| `FFTW_REDFT00` | DCT-I | 自身 | `2(n-1)` |
| `FFTW_REDFT10` | DCT-II | `FFTW_REDFT01` | `2n` |
| `FFTW_REDFT01` | DCT-III | `FFTW_REDFT10` | `2n` |
| `FFTW_REDFT11` | DCT-IV | 自身 | `2n` |
| `FFTW_RODFT00` | DST-I | 自身 | `2(n+1)` |
| `FFTW_RODFT10` | DST-II | `FFTW_RODFT01` | `2n` |
| `FFTW_RODFT01` | DST-III | `FFTW_RODFT10` | `2n` |
| `FFTW_RODFT11` | DST-IV | 自身 | `2n` |

多维 R2R 的总缩放因子为各维逻辑长度 `N` 的乘积。`FFTW_REDFT00` 不定义 `n = 1` 的情形。

### 6.3.6 选择接口层次

| 数据布局 | 推荐接口 | 说明 |
|---|---|---|
| 单次、连续、一至三维 | 基本接口 | 首选，参数最少 |
| 任意秩的连续数组 | 基本 rank 接口 | 使用 `rank` 和维度数组 |
| 多批次、固定步长或嵌入数组 | 高级接口 | 使用 `fftw_plan_many_*` |
| 多层批量、转置或任意步长 | Guru 接口 | 分别描述变换维和批量维 |
| 单维长度或步长超出 `int` | Guru64 接口 | 使用 `fftw_iodim64`，无额外性能优势 |

只在基本接口无法表达布局时再使用高级接口或 Guru 接口。复杂接口不会自动验证调用者分配的实际内存大小。

## 6.4 运行配置

### 6.4.1 Plan 缓存

HygonFFT 可在内部按照规划参数匹配复用 Plan 对象，以降低重复规划和预处理成本。缓存不改变 FFTW 的句柄语义：

- 每次规划成功后，应用都必须保存返回的 Plan。
- 每个不再使用的 Plan 都必须调用 `fftw_destroy_plan`。
- 有了复用之后，两次 plan 创建可能返回相同地址，因此不能依赖原有 FFTW 提供的隐式的类似 unique\_address 的保证。
- 对同一变换高频执行时，应用仍应优先保留并重复执行已有 Plan，反复创建的性能代价大幅降低。

### 6.4.2 多线程使用

多线程 Plan 的基本调用顺序如下：

1. 链接目标发行包提供的线程库和顺序库。
2. 在其他 FFTW 线程接口之前调用 `fftw_init_threads`，并检查返回值。
3. 调用 `fftw_plan_with_nthreads` 设置之后创建的 Plan 可使用的最大线程数。
4. 创建并执行 Plan。
5. 销毁所有 Plan 后，按需调用 `fftw_cleanup_threads`。

```c
#include <fftw3.h>
#include <omp.h>

int main(void)
{
    fftw_plan plan;
    fftw_complex *in;
    fftw_complex *out;
    const int n = 1024;

    if (fftw_init_threads() == 0) {
        return 1;
    }

    fftw_plan_with_nthreads(omp_get_max_threads());

    in = fftw_alloc_complex(n);
    out = fftw_alloc_complex(n);
    if (in == NULL || out == NULL) {
        if (in != NULL) fftw_free(in);
        if (out != NULL) fftw_free(out);
        fftw_cleanup_threads();
        return 1;
    }

    plan = fftw_plan_dft_1d(
        n, in, out, FFTW_FORWARD, FFTW_ESTIMATE);
    if (plan == NULL) {
        fftw_free(in);
        fftw_free(out);
        fftw_cleanup_threads();
        return 1;
    }

    for (int i = 0; i < n; ++i) {
        in[i][0] = 0.0;
        in[i][1] = 0.0;
    }
    in[0][0] = 1.0;

    fftw_execute(plan);

    fftw_destroy_plan(plan);
    fftw_free(in);
    fftw_free(out);
    fftw_cleanup_threads();
    return 0;
}
```

线程数在创建 Plan 时确定。之后再次调用 `fftw_plan_with_nthreads` 不会改变已有 Plan。

FFTW 只保证执行函数是线程安全的。Plan 创建、销毁和大多数全局配置函数默认不是线程安全的，应在单一线程中调用，或由应用统一串行化。

### 6.4.3 环境变量

| 变量 | 作用 | 说明 |
|---|---|---|
| `HML_FFT_OMP_NUM_THREADS` | 设置 HygonFFT 默认线程数上限 | 正整数；显式 API 配置的 Plan 不受其追溯影响 |
| `OMP_NUM_THREADS` | 设置 OpenMP 运行时线程团队大小 | 仅对 OpenMP 后端有效 |
| `OMP_PROC_BIND` | 控制 OpenMP 线程绑定 | 语义由 OpenMP 运行时定义 |
| `OMP_PLACES` | 控制 OpenMP 线程放置 | 语义由 OpenMP 运行时定义 |

示例：

```bash
export HML_FFT_OMP_NUM_THREADS=8
export OMP_PROC_BIND=close
export OMP_PLACES=cores
./program
```

若同时设置环境变量并调用 `fftw_plan_with_nthreads`，应使用 `fftw_planner_nthreads()` 检查后续 Plan 的规划器设置。实际执行线程数还可能受到 OpenMP 运行时、进程亲和性和系统资源限制。

## 6.5 函数定义

本节按变换类别组织 C 接口，并为每个接口分别给出用途、原型、参数和返回值。使用者仍然包含 FFTW 头文件并调用 FFTW 接口；HygonFFT 在运行时通过兼容层将调用转入自身实现。

**依赖**

```c
#include <fftw3.h>
```

使用 `FILE *` 时还需包含 `<stdio.h>`；释放 `fftw_sprint_plan` 返回的字符串时需包含 `<stdlib.h>`。线程接口还必须链接目标发行包提供的 FFTW/HygonFFT 线程库。

以下接口以双精度为例。单精度接口使用 `fftwf_*` 前缀，并将 `double`、`fftw_complex` 替换为对应精度类型。HygonFFT 只提供双精度和单精度接口，实际支持的精度和可选接口，以随包头文件、动态符号表及发行说明为准。

| 变换类别 | 输入 | 输出 | 方向参数 | 关键约束 |
|---|---|---|---|---|
| C2C | 复数 | 复数 | `sign` | 支持正向和反向，可原位执行 |
| R2C | 实数 | 厄米压缩复数 | 无 | 固定为正向；最后一维存储 `floor(n/2) + 1` 个复数 |
| C2R | 厄米压缩复数 | 实数 | 无 | 固定为反向；复数输入可能被改写 |
| R2R | 实数 | 实数 | `kind` | 每个变换维分别指定 DCT、DST、DHT 等类型 |

所有规划接口成功时返回非空 Plan，失败时返回 `NULL`。创建 Plan 时传入的数组必须满足尺寸、布局、原位属性和对齐要求；规划器在部分规划模式下可能读取或改写数组，具体约束见 6.3 节。Plan 创建后可以重复执行，使用完毕必须调用 `fftw_destroy_plan`。

高级批量接口中的 `istride`、`ostride`、`idist` 和 `odist` 均按相应数组的元素计数，而不是按字节计数。Guru 接口中的 `dims` 描述变换维，`howmany_dims` 描述批量维：

```c
typedef struct {
    int n;
    int is;
    int os;
} fftw_iodim;

typedef struct {
    ptrdiff_t n;
    ptrdiff_t is;
    ptrdiff_t os;
} fftw_iodim64;
```

Guru64 接口仅扩大长度和步长的整数范围，不提高执行性能。调用者必须保证所有计算得到的数组地址均处于已分配内存内，接口不会接收或检查实际分配长度。

### 6.5.1 C2C 变换

C2C 对复数输入执行复数 DFT。`FFTW_FORWARD` 表示正向变换，`FFTW_BACKWARD` 表示反向变换。FFTW 与 HygonFFT 均不自动归一化。

| 接口 | 说明 |
|---|---|
| `fftw_plan_dft_1d / 2d / 3d` | 创建一至三维连续 C2C Plan |
| `fftw_plan_dft` | 创建任意秩连续 C2C Plan |
| `fftw_plan_many_dft` | 创建批量或带步长 C2C Plan |
| `fftw_plan_guru_dft / guru64_dft` | 创建任意布局的交错复数 C2C Plan |
| `fftw_plan_guru_split_dft / guru64_split_dft` | 创建分离复数 C2C Plan |
| `fftw_execute_dft / fftw_execute_split_dft` | 使用新数组执行对应 C2C Plan |

#### 6.5.1.1 基本规划接口

##### 6.5.1.1.1 fftw\_plan\_dft\_1d

**函数说明**

创建一维连续复数 DFT Plan。输入和输出可以是不同数组；`in == out` 表示原位变换。

**接口定义**

```c
fftw_plan fftw_plan_dft_1d(
    int n, fftw_complex *in, fftw_complex *out,
    int sign, unsigned flags);
```

**参数**

| 参数名 | 说明 |
|---|---|

### 6.5.2 R2C 变换

R2C 将实数数据变换为厄米压缩复数数据，方向固定为正向，因此没有 `sign` 参数。长度为 `n` 的一维输入保存 `floor(n/2) + 1` 个复数输出；多维变换只压缩最后一维。原位填充规则见 6.3.4 节。

| 接口 | 说明 |
|---|---|
| `fftw_plan_dft_r2c_1d / 2d / 3d` | 创建一至三维连续 R2C Plan |
| `fftw_plan_dft_r2c` | 创建任意秩连续 R2C Plan |
| `fftw_plan_many_dft_r2c` | 创建批量或带步长 R2C Plan |
| `fftw_plan_guru_dft_r2c / guru64_dft_r2c` | 创建任意布局的交错输出 R2C Plan |
| `fftw_plan_guru_split_dft_r2c / guru64_split_dft_r2c` | 创建分离复数输出 R2C Plan |
| `fftw_execute_dft_r2c / fftw_execute_split_dft_r2c` | 使用新数组执行对应 R2C Plan |

### 6.5.3 C2R 变换

C2R 将厄米压缩复数数据变换为实数数据，方向固定为反向，因此没有 `sign` 参数。输入必须符合厄米对称压缩布局。C2R 规划或执行通常可能改写复数输入；需要保留输入时应使用副本，并验证当前布局能否使用 `FFTW_PRESERVE_INPUT` 成功创建 Plan。

| 接口 | 说明 |
|---|---|
| `fftw_plan_dft_c2r_1d / 2d / 3d` | 创建一至三维连续 C2R Plan |
| `fftw_plan_dft_c2r` | 创建任意秩连续 C2R Plan |
| `fftw_plan_many_dft_c2r` | 创建批量或带步长 C2R Plan |
| `fftw_plan_guru_dft_c2r / guru64_dft_c2r` | 创建任意布局的交错输入 C2R Plan |
| `fftw_plan_guru_split_dft_c2r / guru64_split_dft_c2r` | 创建分离复数输入 C2R Plan |
| `fftw_execute_dft_c2r / fftw_execute_split_dft_c2r` | 使用新数组执行对应 C2R Plan |

## 6.6 Fortran 接口

### 6.6.1 现代 Fortran 接口

现代接口基于 Fortran 2003 `iso_c_binding`：

```fortran
use, intrinsic :: iso_c_binding
include 'fftw3.f03'
```

常用类型对应关系如下。

| C 类型 | Fortran 类型 |
|---|---|
| `int` | `integer(C_INT)` |
| `size_t` | `integer(C_SIZE_T)` |
| `double` | `real(C_DOUBLE)` |
| `fftw_complex` | `complex(C_DOUBLE_COMPLEX)` |
| `fftw_plan` | `type(C_PTR)` |
| `fftw_r2r_kind` | `integer(C_FFTW_R2R_KIND)` |

C 使用行主序，Fortran 使用列主序。调用现代 C 绑定时应反转维度顺序。例如，Fortran 数组 `a(L,M,N)` 对应 C 接口维度 `N,M,L`。多维 R2C 的压缩维在 Fortran 中对应第一维。

```fortran
type(C_PTR) :: plan
complex(C_DOUBLE_COMPLEX), dimension(1024, 1000) :: in, out

plan = fftw_plan_dft_2d(1000, 1024, in, out, &
                        FFTW_FORWARD, FFTW_ESTIMATE)
if (.not. c_associated(plan)) stop 'plan creation failed'

call fftw_execute_dft(plan, in, out)
call fftw_destroy_plan(plan)
```

现代 Fortran 应优先使用显式带数组参数的类型专用执行函数，以便编译器正确识别数组读写：

- C2C：`fftw_execute_dft`
- R2C：`fftw_execute_dft_r2c`
- C2R：`fftw_execute_dft_c2r`
- R2R：`fftw_execute_r2r`

对齐内存可通过 `fftw_alloc_real` 或 `fftw_alloc_complex` 获取 `C_PTR`，再用 `C_F_POINTER` 关联到 Fortran 指针；释放时调用 `fftw_free`。

### 6.6.2 传统 Fortran 接口

传统接口主要用于 Fortran 77 风格代码。双精度包装函数通常使用 `dfftw_` 前缀，并把 C 函数返回值改为第一个子程序参数；单精度使用 `sfftw_` 前缀。

```fortran
      double complex in, out
      dimension in(N), out(N)
      integer*8 plan

      call dfftw_plan_dft_1d(plan, N, in, out,
     &                       FFTW_FORWARD, FFTW_ESTIMATE)
      call dfftw_execute_dft(plan, in, out)
      call dfftw_destroy_plan(plan)
```

传统包装层会自动处理维度顺序，因此按 Fortran 的自然维度顺序传参。不要把现代 `iso_c_binding` 接口的“手动反转维度”规则套用到传统接口。

传统接口中保存 Plan 的整数类型必须足以容纳 C 指针；`integer*8` 只适用于满足该 ABI 的目标平台。实际代码应遵循发行包提供的 `fftw3.f`、编译器文档和目标平台 ABI，不能把示例中的位宽作为跨平台保证。

## 6.7 数学定义

本节用于核对变换方向、频谱顺序和数值结果。公式中的索引 `j`、`k` 从 0 开始，`n` 为一维长度，字母 i 表示虚数单位。除求和上下限已明确给出的索引外，输出索引 `k` 的范围均为 0 至 `n-1`。

### 6.7.1 复数 DFT

正向变换为：

$$
Y\_k
\= \\sum\_{j=0}^{n-1}
X\_j e^{-2\\pi \\mathrm{i}jk/n}.
$$

反向变换为：

$$
Y\_k
\= \\sum\_{j=0}^{n-1}
X\_j e^{2\\pi \\mathrm{i}jk/n}.
$$

零频率位于索引 0，负频率按周期顺序位于数组后半部分。接口不会自动执行 `fftshift`。

### 6.7.2 实数 DFT

实数输入的完整频谱满足厄米对称：

$$
Y\_k = Y\_{n-k}^{\*}.
$$

其中频率下标按 `n` 取模；因此 `k = 0` 时等式右侧仍表示 `Y_0`。

多维形式为：

$$
Y\[k\_0,\\ldots,k\_{d-1}\]
===

Y\[n\_0-k\_0,\\ldots,n\_{d-1}-k\_{d-1}\]^{\*}.
$$

物理数组只保存最后一维的非冗余部分，但对称关系同时涉及所有维度。

多维公式中的每个频率下标分别按对应维度长度取模。

### 6.7.3 DCT 与 DST

四类 DCT 的定义如下。

`FFTW_REDFT00`：

$$
Y\_k
\= X\_0 + (-1)^k X\_{n-1}

+ 2\\sum\_{j=1}^{n-2}
  X\_j
  \\cos\\left(\\frac{\\pi jk}{n-1}\\right).
  $$

`FFTW_REDFT10`：

$$
Y\_k
\= 2\\sum\_{j=0}^{n-1}
X\_j
\\cos\\left(\\frac{\\pi(j+1/2)k}{n}\\right).
$$

`FFTW_REDFT01`：

$$
Y\_k
\= X\_0

+ 2\\sum\_{j=1}^{n-1}
  X\_j
  \\cos\\left(\\frac{\\pi j(k+1/2)}{n}\\right).
  $$

`FFTW_REDFT11`：

$$
Y\_k
\= 2\\sum\_{j=0}^{n-1}
X\_j
\\cos\\left(
\\frac{\\pi(j+1/2)(k+1/2)}{n}
\\right).
$$

四类 DST 的定义如下。

`FFTW_RODFT00`：

$$
Y\_k
\= 2\\sum\_{j=0}^{n-1}
X\_j
\\sin\\left(
\\frac{\\pi(j+1)(k+1)}{n+1}
\\right).
$$

`FFTW_RODFT10`：

$$
Y\_k
\= 2\\sum\_{j=0}^{n-1}
X\_j
\\sin\\left(
\\frac{\\pi(j+1/2)(k+1)}{n}
\\right).
$$

`FFTW_RODFT01`：

$$
Y\_k
\= (-1)^k X\_{n-1}

+ 2\\sum\_{j=0}^{n-2}
  X\_j
  \\sin\\left(
  \\frac{\\pi(j+1)(k+1/2)}{n}
  \\right).
  $$

`FFTW_RODFT11`：

$$
Y\_k
\= 2\\sum\_{j=0}^{n-1}
X\_j
\\sin\\left(
\\frac{\\pi(j+1/2)(k+1/2)}{n}
\\right).
$$

FFTW 不包含部分文献为正交化而引入的额外缩放。

### 6.7.4 DHT 与多维缩放

离散哈特莱变换定义为：

$$
Y\_k
\= \\sum\_{j=0}^{n-1}
X\_j
\\left\[
\\cos\\left(\\frac{2\\pi jk}{n}\\right)
+
\\sin\\left(\\frac{2\\pi jk}{n}\\right)
\\right\].
$$

DHT 自身为未归一化逆变换，连续执行两次会使输入乘以 `n`。多维 C2C/R2C/C2R 往返变换的缩放因子为：

$$
\\prod\_{s=0}^{d-1} n\_s.
$$

多维 R2R 使用 6.3.5 节所列各维逻辑长度的乘积作为缩放因子。

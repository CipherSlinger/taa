# 4. HygonVML库函数说明

## 4.1 函数说明

HygonVML 即海光向量数学库，提供基本数学运算、三角函数、反三角函数、双曲函数、反双曲函数、指数与对数函数、幂与根函数、取整函数、误差函数、特殊函数及其他数学函数的向量实现。HygonVML 基于海光 CPU 架构进行算法、指令和编译优化，以提升向量计算性能。

## 4.2 接口规范说明

HygonVML 提供数组接口和编译器接口两种向量接口。

### 4.2.1 HygonVML数组接口

数组接口也叫长向量（VML）接口，其接口名称的基本格式如下：

```c
v<dtype><FuncName>
```

- `<dtype>` 表示精度类型，可能的值包括 `s`、`d`、`c`、`z`。
- `<FuncName>` 表示函数名称，采用大驼峰格式，例如 `InvSqrt`。

根据接口函数输入和输出参数个数的不同，HygonVML数组接口可以分为以下5种类型：

1. 输入一个向量，返回一个向量：

```c
void v<dtype><Funcname>(const VML_INT n, const <dtype_c>* a, <dtype_c>* y);
```

常见于一元函数的计算。
2\. 输入两个向量，返回一个向量：

```c
void v<dtype><Funcname>(const VML_INT n, const <dtype_c>* a, const <dtype_c>* b, <dtype_c>* y);
```

常见于二元函数的计算。
3\. 输入一个向量，返回两个向量：

```c
void v<dtype><Funcname>(const VML_INT n, const <dtype_c>* a, <dtype_c>* y, <dtype_c>* z);
```

用于计算 `sincos` ，该计算同时返回变量的正弦和余弦值。
4\. 输入一个向量和一个标量，返回一个向量：

```c
void v<dtype><Funcname>(const VML_INT n, const <dtype_c>* a, const <dtype_c> b, <dtype_c>* y);
```

用于 `powx` 函数的计算。
5\. 输入两个向量和两组标量，返回一个向量：

```c
void v<dtype><Funcname>(const VML_INT n, const <dtype_c>* a, const <dtype_c>* b, const <dtype_c> scalea, const <dtype_c> shifta, const <dtype_c> scaleb, const <dtype_c> shiftb, <dtype_c>* y);
```

用于计算 `linearfrac` ，该计算返回 `(a*scalea+shifta)/(b*scaleb+shiftb)` 的结果。

**接口解释**

- `VML_INT` 代表整型，根据机器的不同，可能是 `int` 或 `long` 类型
- `<dtype_c>` 代表传入数组中数据所属的浮点类型，与 `<dtype>` 一一对应
  - `<dtype>=s` 对应 `<dtype_c>=float`
  - `<dtype>=d` 对应 `<dtype_c>=double`
  - `<dtype>=c` 对应 `<dtype_c>=VML_COMPLEX8`, `VML_COMPLEX8` 结构体定义在 `hygonvml_common.h` 中
  - `<dtype>=z` 对应 `<dtype_c>=VML_COMPLEX16`, `VML_COMPLEX16` 结构体定义在 `hygonvml_common.h` 中
- 参数 `n` 代表输入数组的长度

> **说明：** 所有输入和输出的数组需保持相同的长度 `n` 。

- 参数 `a` 是第一个输入数组的指针，必须为 `const` 类型。
- 参数 `b` 是第二个输入数组的指针，必须为 `const` 类型。
- 参数 `y` 是第一个输出数组的指针
- 参数 `z` 是第二个输出数组的指针

> **说明：** 数组接口函数没有返回值，通过传递输出数组的指针的方式完成结果的存放。

### 4.2.2 HygonVML编译器接口

编译器接口也叫短向量（SVML）接口，其接口名称的基本格式如下：

```c
hvml_v<dtype><vfactor>_<funcname>
```

- `<dtype>` 表示精度类型，可能的值包括 `s`、`d`。
- `<vfactor>` 表示向量化因子（Vectorization Factor），代表并行计算的元素个数。
- `<funcname>` 表示函数名称，采用全小写格式，例如 `invsqrt`。

> `<FuncName>` 与 `<funcname>` 的命名不同：前者采用大驼峰格式，后者采用全小写格式。

HygonVML编译器接口，又被称为短向量接口。根据函数的原型，可以将HygonVML编译器接口划分为以下类型：

1. A-Y类型：

```c
__m<vlen>[d] hvml_v<dtype><vfactor>_<funcname>(__m<vlen>[d] a);
```

输入向量变量 `a` ，返回向量结果 `y` 。
2\. AB-Y类型：

```c
__m<vlen>[d] hvml_v<dtype><vfactor>_<funcname>(__m<vlen>[d] a, __m<vlen>[d] b);
```

输入向量变量 `a` 和 `b` ，返回向量结果 `y` 。
3\. SINCOS类型：

```c
void hvml_v<dtype><vfactor>_sincos(__m<vlen>[d] a, __m<vlen>[d]* ys, __m<vlen>[d]* yc);
```

输入向量变量 `a` 、存储 `sin(a)` 的向量指针 `ys` 及存储 `cos(a)` 的向量指针 `yc` 。

> **说明：** SINCOS接口无返回值； `ys` 和 `yc` 是向量的指针，不是指针向量。

> **重要：** v1.5.0：接口变更为 `void sincos(a, *ys, *yc);` 形式。

4. MODF类型：

```c
__m<vlen>[d] hvml_v<dtype><vfactor>_modf(__m<vlen>[d] a, __m<vlen>[d]* y_int);
```

> **重要：** v1.7.0: 接口变更为 `__m<vlen>[d] modf(a, *y_int);` 形式。

5. CA-CY类型

```c
__m<vlen>[d] hvml_v<dtype><vfactor>_<funcname>(__m<vlen>[d] a);
```

输入复数向量变量 `a` ，返回复数向量结果 `y` 。

> **说明：** 复数的实部和虚部连续存储在向量寄存器中，即 `a[0]=real(X₀), a[1]=imag(X₀)` 。

6. CACB-CY类型

```c
__m<vlen>[d] hvml_v<dtype><vfactor>_<funcname>(__m<vlen>[d] a, __m<vlen>[d] b);
```

输入复数向量变量 `a` 和 `b` ，返回复数向量结果 `y` 。

> **说明：** 复数的实部和虚部连续存储在向量寄存器中，即 `a[0]=real(X₀), a[1]=imag(X₀)` 。

7. LINEARFRAC类型

```c
__m<vlen>[d] hvml_v<dtype><vfactor>_linearfrac(__m<vlen>[d] a, __m<vlen>[d] b,
                                               <dtype> scalea, <dtype> shifta,
                                               <dtype> scaleb, <dtype> shiftb);
```

输入向量变量 `a` 和 `b` ，标量变量 `scalea` 、 `shifta` 、 `scaleb` 、 `shiftb` ，返回向量结果 `y` 。

**接口解释**

- `__m<vlen>[d]` 代表在SSE和AVX等指令集中支持的向量数据类型
  - `<vlen>` 代表向量长度，可能的取值包括 `128` 、 `256` 、 `512` 等
  - `[d]` 代表可能取字母 `d` 为后缀
- `<dtype>` 代表浮点数精度，可能的取值包括 `s` 和 `d`
- `<vfactor>` 表示 _向量化因子（Vectorization Factor）_ ，代表并行计算的元素个数，可能的取值包括 `2` 、 `4` 、 `8` 、 `16` 等
- `<funcname>` 代表函数名称

##### 4.4.1.1.1 v?Add

计算下一个可表示浮点数的函数

**函数说明**

计算向量 `a` 中元素沿向量 `b` 中对应元素方向的下一个可表示浮点数，并将结果存入向量 `y` 。

公式：

$$
\\begin{align}
{y\_0,\\quad y\_1,\\quad\\dots,\\quad y\_{n-1}} \&= {\\text{Float}(\\text{Int}(a)\\pm\\text{1}),\\quad \\text{Float}(\\text{Int}(a)\\pm\\text{1}),\\quad\\dots,\\quad \\text{Float}(\\text{Int}(a)\\pm\\text{1})}
\\end{align}
$$

**接口定义**

C interface：

```c
__m128 hvml_vs4_nextafter(__m128 a, __m128 b);
__m256 hvml_vs8_nextafter(__m256 a, __m256 b);
__m128d hvml_vd2_nextafter(__m128d a, __m128d b);
__m256d hvml_vd4_nextafter(__m256d a, __m256d b);
```

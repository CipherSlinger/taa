# 1. HygonBLAS库函数说明

## 1.1 函数说明

BLAS（Basic Linear Algebra Subprograms，基础线性代数子程序库）是核心的线性代数基础函数库，广泛应用于高性能计算、科学研究及工程技术等领域，支持向量间、矩阵-向量以及矩阵间的各类线性代数运算。

HygonBLAS库是针对海光CPU架构深度优化的线性代数函数库，能够充分释放海光（Hygon）高性能CPU的运算潜能，该库同时提供BLAS标准函数的C语言与Fortran双语言接口。

## 1.2 接口规范说明

BLAS原生标准接口基于Fortran77定义，支持Fortran程序直接调用，函数采用“\<数据类型\>\<函数名\>”的命名规则。
以矩阵乘法运算为例，DGEMM()即为双精度通用矩阵乘法的标准Fortran接口。CBLAS接口是在原生BLAS接口基础上拓展的C语言专用接口，针对内存数据布局提供了更为丰富、灵活的参数配置能力，适配C语言程序的调用场景。在命名规范上，CBLAS接口函数统一在原生BLAS函数名前增加“cblas\_”前缀，例如双精度矩阵乘法的C语言接口为cblas\_dgemm()。

本文后续所有函数功能描述均以CBLAS接口为标准，并同步配套对应的Fortran接口调用示例进行说明。

#### 1.4.1.1 cblas\_?asum

**函数说明**

计算向量元素绝对值之和。对于复数元素，绝对值按实部与虚部绝对值之和计算。

公式：

$$
r = \\sum\_{i=0}^{n-1} |x\_i|
$$

**接口定义**

C interface：

```c
float  cblas_sasum (int n, const float  *x, int incx);
double cblas_dasum (int n, const double *x, int incx);
float  cblas_scasum(int n, const void   *x, int incx);
double cblas_dzasum(int n, const void   *x, int incx);
```

Fortran interface：

```fortran
res = sasum (n, x, incx)
res = dasum (n, x, incx)
res = scasum(n, x, incx)
res = dzasum(n, x, incx)
```

## 1.5 多线程设置

HygonBLAS 的多线程并行由 OpenMP 实现。用户可以通过多线程设置接口或环境变量指定参与运算的线程数。线程数的解析遵循固定优先级，从高到低依次为：

```text
local 覆盖 > HML API > HML 环境变量 > OpenMP 当前配置
```

说明：

- `local` 覆盖仅对当前线程的下一次线程数消费查询生效，读取后自动清零；非正值表示清除该覆盖。
- HML API 与 local 状态按调用线程保存（thread-local），不同线程互不影响。
- 处于活动的 OpenMP 并行区内时，线程数查询直接返回 1，且不消费 local 覆盖。
- HML 环境变量在首次查询时缓存，非法值或非正值将被跳过。
- OpenMP 配置仅在显式设置了非空的 `OMP_NUM_THREADS` 时才通过 `omp_get_max_threads()` 动态读取；未设置时默认返回 1，此时单独调用 `omp_set_num_threads()` 不会启用 HygonBLAS 多线程。
- API 设置的非正值仅清除对应的 HML 覆盖，不改变 OpenMP 的既有配置。
- 上述线程数为请求值，实际参与运算的线程数还可能受算子自身策略、OpenMP 运行时、进程亲和性及系统资源限制。

# 5. HygonLibM库函数说明

## 5.1 函数说明

HygonLibM 提供与 `math.h` 兼容的标量数学接口。

## 5.2 接口规范说明

HygonLibM 提供兼容 `math.h` 的标量接口供用户使用。

HygonLibM 标量接口又被称为基础数学函数接口，其接口格式完全与 `math.h` 中定义的接口格式一致。

## 5.3 数据结构

目前 HygonLibM 所有标量接口都支持的数据类型包括单精度浮点型（`float`）和双精度浮点型（`double`），暂未对所有接口支持扩展精度浮点型（`long double`）。

## 5.4 函数定义

HygonLibM 的标量函数按功能可分为：四则运算函数、三角函数、反三角函数、双曲函数、反双曲函数、指数和对数函数、幂和根函数、取整函数、误差函数、特殊函数、其他函数。

### 5.4.1 四则运算函数

#### 5.4.1.1 remainder\[f\]

取余数（向最近邻取整）函数

**函数说明**

将 `a` 和 `b` 的值相除后取余数（ `a` % `b` ），并返回计算结果。

公式：

$$
\\begin{align}
{y} \&= {a - \\text{RoundToNearest}(\\frac{a}{b})}
\\end{align}
$$

**接口定义**

C interface：

```c
float remainderf(float a, float b);
double remainder(double a, double b);
```

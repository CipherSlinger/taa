# 2. HygonSPARSE库函数说明

## 2.1 函数说明

Sparse BLAS（Sparse Basic Linear Algebra Subprograms）是稀疏矩阵的基本线性代数函数库，在科学计算、工程应用、数据挖掘、人工智能、图形处理等领域有着广泛的应用。
稀疏矩阵的存储和运算需要特殊的方法和技术，以节省空间和时间，提高效率和精度，包含了以压缩形式存储的稀疏向量、稀疏矩阵、稠密向量，以及稀疏矩阵与稠密或稀疏对象之间的线性代数运算操作。
基于海光CPU架构优化的Sparse BLAS库能够更好发挥高性能Hygon CPU的运算能力，HygonSPARSE库提供了Sparse BLAS函数的C语言接口。

## 2.2 接口规范说明

按照美国国家标准与技术研究院（NIST）开发的一种基于C语言的稀疏Sparse库，支持多种存储格式以及矩阵结构，遵循BLAS技术论坛的标准接口。
对于Level1，函数命名一般为：`hml_sparse_<数据类型><操作类型>`，以稀疏向量乘标量为例，`hml_sparse_d_axpy()`表示双精度稀疏向量乘标量接口。
对于Level2和3，函数命名一般为：`hml_sparse_[<数据类型>]<操作类型>[矩阵存储格式]`，以稀疏矩阵乘稠密向量为例，`hml_sparse_d_mv()`表示双精度稀疏矩阵乘稠密向量接口。

### 2.3.4 数据存储

**稀疏向量压缩存储格式**

仅存储稀疏向量中的非零元素。

假设a是一个存储在数组中的向量，a中只有nz个非零元素：a(k1), a(k2), a(knz)。

在稀疏BLAS中，该向量可以用两个数组x(值)和indx(索引)的压缩形式表示。

每个数组有nz个元素：

x(1)=a(k1), x(2)=a(k2), x(nz)=a(knz)

indx(1)=k1, indx(2)=k2, indx(nz)=knz

稀疏向量完全由三元组(nz, x, indx)决定，压缩存储格式可以节省计算机内存和运行时间。

**向量全存储格式**

稀疏的BLAS例程也可以使用完全存储在单个数组(全存储向量)中的数组参数。

如果y是一个全存储向量，它的元素必须连续存储：y\[0\]中的第一个元素，y\[1\]中的第二个元素，以此类推。

这对应于BLAS level1中的增量incy=1。

全存储向量的增量值不会作为参数传递给稀疏的BLAS例程或函数。

**稀疏矩阵存储格式**

CSR(Compressed Sparse Row，行序稀疏矩阵压缩)格式包含四项要素：值(values)、列(columns)、索引B(pointerB)和索引E(pointerE)。

#### 2.4.1.1 hml\_sparse\_?\_axpy

计算压缩稀疏向量和标量的点积，然后再加上一个全存储稀疏向量，即 y = a × x + y。a是一个标量，x是一个以压缩形式存储的稀疏向量，y是全存储形式的向量，例程只引用或修改索引在数组index中列出的y中的元素。

indx中的值必须是不同的。

hml_sparse_status_t hml_sparse_c_axpy(const HML_INT nz, const HML_Complex8 a, const HML_Complex8 *x, const HML_INT *indx, HML_Complex8 *y);

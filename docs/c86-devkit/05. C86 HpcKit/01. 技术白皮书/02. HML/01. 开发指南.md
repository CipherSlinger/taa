# 综述

海光CPU是基于X86架构的国产高性能处理器，海光数学库HML（Hygon Math Library）是海光公司提供的基于海光CPU平台优化的一整套高性能数学函数库，能够更加高效的发挥海光CPU性能，加速用户应用计算。HML包括基础线性代数运算，初等函数运算等，主要完成标量、向量以及矩阵上的各种数学计算。本文档提供了HML的安装指南、详细接口定义与示例代码，旨在帮助用户快速熟悉HML的使用。

# HML库介绍

HML提供了基于海光平台优化的高性能数学函数，所有接口由C/C++、汇编语言实现，部分接口兼容Fortran语言调用。

# 安装指导

## 安装要求

确保gcc版本大于等于8.5.0。

## 下载安装包

RPM和DEB安装包地址：
[**下载地址**](https://download.sourcefind.cn:65024/8/main/c86-devkit/latest/hpc)

## 包命名规则

包命名规则如下：hml-\<version\>-\<buildid\>.\<platform\>.\<rpm/deb\>  
如： hml-1.6.0-251218.4.x86\_64.rpm。

## RPM安装

### 安装

```shell
sudo rpm -Uvh hml-1.6.0-251218.4.x86_64.rpm
```

### 检查是否安装成功

```shell
rpm -qi hml
```

### 显示安装路径

```shell
rpm -ql hml
```

### 卸载

```shell
sudo rpm --verbose --erase hml
```

## DEB安装

### 检查DEB信息

```shell
dpkg -I hml_1.6.0-251218-4.x86_64.deb
```

### 安装

```shell
sudo dpkg -i hml_1.6.0-251218-4.x86_64.deb
```

### 检查是否安装成功

```shell
dpkg -l hml
```

### 卸载

```shell
sudo dpkg -r hml
```

# Hygon C86 HPC Kit 简介

## 简介

C86 HPC Kit 是面向高性能计算场景的统一开发与运行环境的软件包，集成编译器、MPI、数学库等工具链组件，适用于 Hygon C86 平台的 HPC 开发与部署。

### 组件说明

| 组件名称 | 描述 |
|------|------|
| HCC 编译器 | 基于 Clang/LLVM 的 Hygon 编译器，支持 C/C++/Fortran。 |
| HGCC 编译器 | 基于 GCC 的 Hygon 编译器，支持 C/C++/Fortran。 |
| HMPI | 基于 Open MPI 优化的高性能 MPI 通讯库，适配 Hygon 平台。 |
| HML | 数学库，提供高性能计算基础函数。 |

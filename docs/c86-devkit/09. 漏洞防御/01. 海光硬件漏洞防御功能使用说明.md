## 海光IBRS功能

```
海光处理器C86-4G开始支持硬件漏洞防御功能IBRS，基于最新的内核版本，默认使能IBRS。
当使用IBRS时，spectre_v2、retbleed、SRSO漏洞的防御措施默认都是使用IBRS进行防御，除非显示指定防御措施为其他配置，例如spec_rstack_overflow=safe-ret。
```

## SRSO漏洞防御

```
ibpb_brtype参数主要用于对SRSO漏洞防御功能进行配置，其结合spectre_v2_user=on参数，能够完成SRSO漏洞跨进程攻击的防御。ibpb_brtype=ibpb-ind时，SRSO漏洞防御在跨进程场景受direct branch分支训练的影响存在一定的攻击风险。ibpb_brtype=ibpb-all时，消除了利用direct branch分支指令进行训练的SRSO漏洞影响，但是存在性能损失。一般情况下在不同进程的地址空间中使用direct branch分支进行训练攻击难度较大，当用户使用spectre_v2_user=on进行跨进程攻击防御时，用户需要结合SRSO跨进程攻击风险和性能影响综合评估是否使用ibpb_brtype=ibpb-all。默认状态下ibpb_brtype=ibpb-all，但是由于默认spectre_v2_user=off，其未对性能有影响。
海光较新的C86-4G处理器不受SRSO影响，无需针对ibpb_brtype参数做任何配置。
```

## 具体配置和漏洞状态

```
a.默认配置是使用IBRS进行漏洞防御，等效于grub的kernel command line参数中配置spectre_v2=ibrs 和ibpb_brtype=ibpb-all，对应漏洞状态如下：
cat /sys/devices/system/cpu/vulnerabilities/spectre_v2
Mitigation: Enhanced / Automatic IBRS, IBPB: conditional, PBRSB-eIBRS: Not affected
cat /sys/devices/system/cpu/vulnerabilities/retbleed
Mitigation: Enhanced IBRS
cat /sys/devices/system/cup/vulnerabilities/spec_rstacck_overflow
Mitigation: Enhanced IBRS

b.使用软件方案进行漏洞防御，在grub的kernel command line参数中配置spectre_v2=retpoline 和ibpb_brtype=ibpb-all(或使用默认ibpb_brtype参数)，对应漏洞状态如下：
cat /sys/devices/system/cpu/vulnerabilities/spectre_v2
Mitigation: Retpolines, IBPB: conditional, STIBP: always-on, RSB filling, PBRSB-eIBRS: Not affected
cat /sys/devices/system/cpu/vulnerabilities/retbleed
Mitigation: untrained return thunk; SMT enabled with STIBP protection
cat /sys/devices/system/cpu/vulnerabilities/spec_rstack_overflow
Mitigation: safe RET

c.使用软件方案进行漏洞防御，在grub的kernel command line参数中配置spectre_v2=retpoline 和ibpb_brtype=ibpb-ind，对应漏洞状态如下：
cat /sys/devices/system/cpu/vulnerabilities/spectre_v2
Mitigation: Retpolines, IBPB: conditional, STIBP: always-on, RSB filling, PBRSB-eIBRS: Not affected
cat /sys/devices/system/cpu/vulnerabilities/retbleed
Mitigation: untrained return thunk; SMT enabled with STIBP protection
cat /sys/devices/system/cpu/vulnerabilities/spec_rstack_overflow
Mitigation: safe RET, no microcode

d.使用硬件功能进行漏洞防御，在grub的kernel command line参数中配置spectre_v2=ibrs和ibpb_brtype=ibpb-all(或使用默认ibpb_brtype参数)，对应漏洞状态如下：
cat /sys/devices/system/cpu/vulnerabilities/spectre_v2
Mitigation: Enhanced / Automatic IBRS, IBPB: conditional, PBRSB-eIBRS: Not affected
cat /sys/devices/system/cpu/vulnerabilities/retbleed
Mitigation: Enhanced IBRS
cat /sys/devices/system/cpu/vulnerabilities/spec_rstacck_overflow
Mitigation: Enhanced IBRS

e.使用硬件功能进行漏洞防御，在grub的kernel command line参数中配置spectre_v2=ibrs 和ibpb_brtype=ibpb-ind，对应漏洞状态如下：
cat /sys/devices/system/cpu/vulnerabilities/spectre_v2
Mitigation: Enhanced / Automatic IBRS, IBPB: conditional, PBRSB-eIBRS: Not affected
cat /sys/devices/system/cpu/vulnerabilities/retbleed
Mitigation: Enhanced IBRS
cat /sys/devices/system/cpu/vulnerabilities/spec_rstack_overflow
Mitigation: Enhanced IBRS, no microcode
```

# HCT密码套件版本说明

| 版本 | 发布日期   | 版本说明         |
| -------- | ---------- | ---------------- |
| hct-1.1.1  | 2023-09-30 | 1. 支持主机环境使用，支持ccp和avx加速 |
| hct-2.1.0  | 2024-10-30 | 1. 新增cis指令集支持，支持新一代海光4G CCP <br> 2. 支持主机，虚拟机，容器环境使用 <br> 3. tkm功能需单独安装hygon-psp-3.3.0 和 hygon-sdf-2.3.0 安装包|
| hct-3.0.10  | 2026-01-03 | 1. 支持vCCP，vTKM热迁移 <br> 2. tkm功能相关库集成到hct中，不需要额外安装psp和sdf库|

# 版本使用建议

- 优先推荐HCT3.x版本。
- HCT2.x 为历史版本，与3.x库不兼容、不可共用，环境切换需彻底卸载另一版本并重启设备。
- HCT2.x 升级3.x版本，除卸载hct-2.x.x安装包外，还需将hysdf、hypsp一并卸载。
- 需配套使用同批次发布包（[下载链接](https://download.sourcefind.cn:65024/8/main/c86-devkit/latest)），如选用 `latest/hct` 镜像，需搭配 `latest/tools` 下 hag 工具，防止跨批次包引发兼容异常。

HCT2.1版本CAE和TKM均支持容器化部署，以下是启动方法：

# 绑定驱动

主机执行以下命令，将CCP绑定到hct驱动上

```
sudo /opt/hygon/hct/hct/script/hctconfig start
```

# 启动容器

容器启动参数针对三种场景进行分别说明，具体如下:

## 场景一：使用CAE

以ubuntu20.04为例，启动容器镜像：

```
docker run -itd --name=hct_test --privileged=true --net=host \
-v /dev/:/dev/ \
-v /lib/modules/:/lib/modules/ \
ubuntu:18.04
```

## 场景二：使用TKM

**注意：** 务必提前在主机环境中，确保SDF环境运行正常。

```
docker run -itd --name=sdf_test --privileged=true --net=host \
-v /dev/:/dev/ \
-v /etc/tkm_rootkey_img:/etc/tkm_rootkey_img \
-v /etc/psp_config:/etc/psp_config \
-v /lib/modules/:/lib/modules/ \
ubuntu:18.04
```

本质上为了支持容器中运行海光SDF接口，需要确保以下几点：

- 共享映射/etc/tkm\_rootkey\_img、/etc/psp\_config、/dev/、/lib/modules/
- 使能特权权限：--privileged=true

**注意**：如宿主机不存在/etc/tkm\_rootkey\_img，/etc/psp\_config两个文件，则应当执行以下命令创建两个空文件，否则docker将会作为目录进行映射导致错误。

```
$ touch /etc/tkm_rootkey_img /etc/psp_config
```

# 基本测试

进入容器：

```
docker exec -it cae_test bash
```

容器测试环境与主机类似，用户需确保容器中openssl运行环境正常，**容器中**同样需要安装相关依赖，若已安装则跳过该步骤：

- 依赖安装：

```
sudo apt install libnuma-dev
或
sudo yum install numactl -y
```

## 容器内套件安装

- CAE套件安装：

```
sudo dpkg -i hct-2.1.0-2024-1030-release.x86_64.deb
或
sudo rpm -i hct-2.1.0-2024-1030-release.x86_64.rpm
(如果安装过旧版本hct，先执行rpm -e hct卸载旧版本)
```

- TKM套件安装

参考[主机环境搭建](<01. 主机环境搭建.md>)`3.2节软件包安装`，在容器内分别安装好hct、tkm、sdf三个组件的软件包，无需再次导入证书和安装内核模块。

## 运行测试程序

- 测试CAE

```
cd /opt/hygon/hct/bin
./hct_test
```

- 测试TKM
  参考[主机环境搭建](<01. 主机环境搭建.md>)`3.3节基本测试验证`中相同的测试方式，在容器内进行测试验证。

HCT3.0版本CAE和TKM均支持容器化部署，和主机上使用HCT一样，同样支持基于ccp驱动或vfio-pci驱动启动容器，以下是启动方法：

# 1. 绑定驱动

```
sudo /opt/hygon/hct/hct/script/hctconfig start
```

# 2. 启动容器

容器启动参数针对三种场景进行分别说明，具体如下:

## 2.1 场景一：使用CAE

以ubuntu20.04为例，启动容器镜像：

```
docker run -itd --name=cae_test --privileged=true --net=host \
-v /dev/shm/:/dev/shm/ -v /dev/hugepages/:/dev/hugepages/  \
-v /run/hct/:/opt/hygon/hct/run/hct/ \
-v /etc/psp_config:/etc/psp_config \
--device /dev/sev \
--device /dev/hygon_psp_config \
--device /dev/hygon_psp_resource2 \
ubuntu:22.04 \
/bin/bash
```

进入容器：

```
docker exec -it cae_test bash
```

容器下驱动安装与验证见下面“基本测试”章节说明

## 2.2 场景二：使用共享主机密钥的TKM

以kylin-v10sp3为例，启动容器镜像：

```
docker run -itd --name=sdf_test --privileged=true --net=host \
-v /dev/shm/:/dev/shm/ -v /dev/hugepages/:/dev/hugepages/  \
-v /run/hct/:/opt/hygon/hct/run/hct/ \
-v /etc/psp_config:/etc/psp_config \
-v /etc/tkm_rootkey_img:/etc/tkm_rootkey_img \
--device /dev/sev \
--device /dev/hygon_psp_config \
--device /dev/hygon_psp_resource2 \
cr.kylinos.cn/kylin/kylin-server-init:v10sp3 \
/usr/sbin/init
```

进入容器：

```
docker exec -it sdf_test bash
```

容器下驱动安装与验证见下面“基本测试”章节说明

## 2.3 场景三：使用密钥隔离的TKM

容器中使用支持密钥隔离的tkm功能，需额外补充

```
--env TKM_VID=<NUM>
```

其中`<NUM>`应替换成实际的vid值，vid创建命令为：

```
hag tkm vtkm_create -mode exclusive
```

支持容器下的密钥隔离，应满足以下要求：
|配置|要求|
|:-----|:-----|
|BIOS|安全固件版本为2070或以上|
|HCT|3.0.10及以上|
|hag|2404或以上|

以anolisos:8.10为例，启动容器镜像：

```
docker run -itd --name=sdf_test --privileged=true --net=host \
-v /dev/shm/:/dev/shm/ -v /dev/hugepages/:/dev/hugepages/  \
-v /run/hct/:/opt/hygon/hct/run/hct/ \
-v /etc/psp_config:/etc/psp_config \
--device /dev/sev \
--device /dev/hygon_psp_config \
--device /dev/hygon_psp_resource2 \
--env TKM_VID=1 \
registry.openanolis.cn/openanolis/anolisos:8.10 \
/usr/sbin/init

```

进入容器：

```
docker exec -it sdf_test bash
```

容器下驱动安装与验证见下面“基本测试”章节说明

# 3. 基本测试

测试前需要在容器中将相关依赖与驱动包进行安装，若已安装则跳过该步骤：

- 依赖安装：

```
sudo apt install libnuma-dev
或
sudo yum install numactl -y
```

- 开发套件安装：

```
sudo dpkg -i hct-3.0.12-2603d14.x86_64.deb
或
sudo rpm -i --nodeps hct-3.0.12-2603d14.x86_64.rpm
(如果安装过旧版本hct，先执行rpm -e hct卸载旧版本)
```

## 3.1 场景一测试：

测试前请参考《HCT主机环境搭建》中“安装openssl/Tongsuo库”节描述部分，确保本机的openssl没有兼容性问题。

```
/opt/hygon/hct/bin/hct_test
```

## 3.2 场景二与场景三测试：

- 出厂基础用例测试：

```
/opt/hygon/hct/bin/sdf_test -idx 10 -password 11223344
```

所有用例均success表示测试通过。

- 性能测试工具使用：

```
/opt/hygon/hct/bin/sdf_speed
```

通过以上命令可以输出测试方法与支持的接口，根据实际需要进行性能测试。

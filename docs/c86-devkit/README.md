# C86 DevKit 官方文档（本地镜像）

海光 C86 DevKit 官方文档站的完整离线副本，作为 CSV 宿主机 / 加密虚拟机配置的参考手册。

- 源站：<https://c86.sourcefind.cn/documents/2/>（需登录，光合开发者社区 SSO）
- 抓取时间：2026-11-19
- 规模：184 篇 Markdown，图片 420 个文件
- 正文为官方原始 Markdown；图片已下载到 `_assets/` 并改写为相对链接
- 每篇带 frontmatter：`title` / `docCode` / `updated` / `breadcrumb` / `source`

## 建议阅读顺序（CSV 宿主机配置）

1. `01. 机密计算/01. 技术白皮书/` —— 先建立 CSV/CSV2/CSV3 与远程认证、密钥封印、磁盘加密的概念
2. `01. 机密计算/02. 用户指南/01. 环境部署/` —— 宿主机侧环境要求、OS、公共软件、编译安装
3. `01. 机密计算/02. 用户指南/02. 主机测试/` 与 `03. 测试加密虚拟机/` —— 逐项验证步骤，含 QEMU 启动参数
4. `01. 机密计算/04. 测试KATA机密容器/` —— Kata + CSV2 机密容器
5. `03. 密码技术/` —— HCT / TKM，对应仓库里的 HCT 客户端

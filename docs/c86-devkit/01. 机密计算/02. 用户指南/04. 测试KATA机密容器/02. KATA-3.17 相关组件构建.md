# 构建机密容器的kata重要组件

---

本环境构建使用ubuntu22.04 虚拟机

```
wget  https://download.sourcefind.cn:65024/directlink/8/c86-devkit/previous-release/csv/jammy-server-cloudimg-amd64.img
# 运行虚拟机，虚拟机root 用户的密码为root，这里设置了比较大的虚拟机内存，目前各个组件是在/dev/shm 共享内存中编译的，占用内存比较多
qemu-system-x86_64 -name vm --enable-kvm -cpu host -m 80960 -hda /home/higon/jammy-server-cloudimg-amd64.img -drive if=pflash,format=raw,unit=0,file=/usr/share/edk2/ovmf/OVMF_CODE.fd,readonly=on -qmp tcp:127.0.0.1:2222,server,nowait -vnc 0.0.0.0:0 -netdev bridge,br=virbr0,id=net0 -device virtio-net-pci,netdev=net0,romfile= -nographic
```

> **注意：** 后续 guest 相关组件操作都在该虚拟机中进行。

> 为了简单起见，请下载该仓库，并切换到tools/build-and-install/build-in-ubuntu22.04/

```shell
git clone https://gitee.com/hanliyang-kata-coco/deployment -b kata-3.17
cd deployment/tools/build-and-install/build-in-ubuntu22.04/
```

## 准备构建环境所须的docker,go,rust等

```shell
./build-setup-go-rust-docker-etc.sh
```

## 构建coco operator kata-deploy image需要的组件

### 构建containerd-shim-kata-v2, kata-runtime等

```shell
./build-kata-runtime.sh
```

### 构建qemu

```shell
TARGET_DISTRO=openeuler \
TARGET_DISTRO_VERSION=24.03 \
./build-kata-qemu.sh
```

### 构建ovmf

```shell
TARGET_DISTRO=openeuler \
TARGET_DISTRO_VERSION=24.03 \
./build-kata-ovmf.sh
```

### 构建kata-agent

```shell
./build-kata-agent.sh
```

### 构建guest-pause-rootfs

```shell
./build-kata-guest-pause.sh
```

### 构建guest-components(AA,CDH,ASR,luks-encrypt-storage)

```shell
./build-kata-coco-guest-components.sh
```

### 构建guest kernel（不包含DCU支持）

```shell
TARGET_DISTRO=openeuler \
TARGET_DISTRO_VERSION=24.03 \
./build-kata-guest-kernel.sh
```

### 构建guest initrd（不包含DCU支持）

```shell
TARGET_DISTRO=openeuler \
TARGET_DISTRO_VERSION=24.03 \
./build-kata-guest-initrd.sh
```

### 构建guest image（不包含DCU支持）

```shell
TARGET_DISTRO=openeuler \
TARGET_DISTRO_VERSION=24.03 \
./build-kata-guest-image.sh
```

### 构建guest kernel（包含DCU支持）

```shell
TARGET_DISTRO=openeuler \
TARGET_DISTRO_VERSION=24.03 \
./build-kata-guest-kernel.sh -g
```

### 构建guest image（包含DCU支持）

* 用户需要提供参数 `-f /path/to/rock...run` 指定要集成的HYCU驱动版本
* 目前支持以下版本：
  - rock-6.3.13-V1.12.0.run
  - rock-6.3.15-V1.0.1a.run
  - rock-6.3.32-V1.6.0.run

```shell
run_file_path="$HOME/workspace/CoCo/rock-6.3.32-V1.6.0.run"

TARGET_DISTRO=openeuler \
TARGET_DISTRO_VERSION=24.03 \
./build-kata-guest-image.sh -g -f ${run_file_path}
```

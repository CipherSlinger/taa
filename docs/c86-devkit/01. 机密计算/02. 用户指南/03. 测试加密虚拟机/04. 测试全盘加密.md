## 功能描述

操作系统使用的磁盘包含启动分区和数据分区，全盘加密是指将启动分区和数据分区全部加密，保证系统的所有文件都不会被窃取或者篡改，本文描述了CSV虚拟机使用全盘加密的方法。

测试中遇到问题请先查看下面问题列表中是否有相关解决方案：

[常见问题 - 机密虚拟机](<../../04. 常见问题/04. 机密虚拟机.md>)

## 测试全盘加密功能

下面提供了几种制作主流虚拟机类型加密镜像的方法，客户根据需求选择要制作的虚拟机镜像。

### 制作全盘加密的虚拟机镜像 - ubuntu-18.04

使用ISO镜像安装虚拟机，安装过程选择<normal install>，<install type>选择磁盘加密<Encrypt the new Ubuntu installation for security>加密/dev/sda3，使用Encpasswd0作为示例密码。

```
cd /opt/hygon/csv/
wget http://mirrors.163.com/ubuntu-releases/18.04/ubuntu-18.04.6-desktop-amd64.iso
qemu-img create -f qcow2 encrypt.qcow2 50g
sudo qemu-system-x86_64 -enable-kvm -cpu host -smp 4 -m 4096 -drive if=pflash,format=raw,unit=0,file=/opt/hygon/csv/OVMF_CODE.fd,readonly=on -hda ./encrypt.qcow2 -boot d -cdrom ./ubuntu-18.04.6-desktop-amd64.iso -vnc 0.0.0.0:1
```

安装完成后重启虚拟机，安装过程中加密了虚拟机的数据分区/dev/sda3，接下来加密启动分区/dev/sda2并替换虚拟机中的grub。
由于虚拟机的分区/dev/sda3已经被加密，启动过程中需要输入密码Encpasswd0进行解密，启动后在虚拟机中使用scp命令将主机中的文件拷贝到虚拟机，这里假设主机的用户名为test，IP地址为192.168.122.1。

```
scp test@192.168.122.1:/opt/hygon/csv/setup-encrypt.sh ./
scp test@192.168.122.1:/opt/hygon/csv/grub.tar.gz ./
sudo ./setup-encrypt.sh
```

脚本setup-encrypt.sh执行过程中，请按提示输入YES（大写）和密码Encpasswd0，执行完成后关闭虚拟机，此时虚拟机的启动分区和数据分区都已经被密码Encpasswd0加密

### 制作全盘加密的虚拟机镜像 - anolis-8.10

使用ISO镜像安装虚拟机，安装过程选择<INTSTALLATION DISTINATION >，<Encryption>选择磁盘加密<Encrypt my data>加密/dev/sda3，使用Encpasswd0作为示例密码。

```
cd /opt/hygon/csv/
wget https://mirrors.openanolis.cn/anolis/8.10/isos/GA/x86_64/AnolisOS-8.10-x86_64-dvd.iso
qemu-img create -f qcow2 encrypt.qcow2 50g
sudo qemu-system-x86_64 -enable-kvm -cpu host -smp 4 -m 4096 -drive if=pflash,format=raw,unit=0,file=/opt/hygon/csv/OVMF_CODE.fd,readonly=on -hda ./encrypt.qcow2 -boot d -cdrom ./AnolisOS-8.10-x86_64-dvd.iso -vnc 0.0.0.0:1
```

安装完成后重启虚拟机，安装过程中加密了虚拟机的数据分区/dev/sda3，接下来加密启动分区/dev/sda2。
启动后在虚拟机中使用scp命令将主机中的文件拷贝到虚拟机，这里假设主机的用户名为test，IP地址为192.168.122.1。

```
# 设置虚拟机网卡为自动启动，ifcfg-ens3 文件根据具体的虚拟机网卡而定，这里为示例
sudo sed -i 's/^ONBOOT=no/ONBOOT=yes/' /etc/sysconfig/network-scripts/ifcfg-ens3
# 使网卡配置修改生效，获取ip地址
sudo systemctl restart NetworkManager
scp test@192.168.122.1:/opt/hygon/csv/setup-encrypt-anolis.sh ./
sudo chmod +x setup-encrypt-anolis.sh
sudo ./setup-encrypt-anolis.sh
```

### 制作全盘加密的虚拟机镜像 - Kylin-Server-V10-SP3-2403

使用ISO镜像安装虚拟机，安装过程选择<INTSTALLATION DISTINATION >，<Encryption>选择磁盘加密<Encrypt my data>加密/dev/sda3，使用Encpasswd0作为示例密码。

```
cd /opt/hygon/csv/
# Kylin-Server-V10-SP3-2403-Release-20240426-X86_64.iso，到麒麟官网申请下载试用，申请链接：https://www.kylinos.cn/support/trial/
# Kylin-Server-V10-SP3-2403 系统自带的OVMF.fd不支持该功能，需要下载支持该功能的OVMF.fd
mv /opt/hygon/csv/OVMF.fd /opt/hygon/csv/OVMF.fd-bk
wget -c  https://download.sourcefind.cn:65024/directlink/8/c86-devkit/previous-release/csv/pkg/OVMF.fd -O  /opt/hygon/csv/OVMF.fd
qemu-img create -f qcow2 encrypt.qcow2 50g
sudo qemu-system-x86_64 -enable-kvm -cpu host -smp 4 -m 4096 -drive if=pflash,format=raw,unit=0,file=/opt/hygon/csv/OVMF_CODE.fd,readonly=on -hda ./encrypt.qcow2 -boot d -cdrom ./Kylin-Server-V10-SP3-2403-Release-20240426-X86_64.iso -vnc 0.0.0.0:1 -netdev bridge,br=virbr0,id=net0 -device virtio-net-pci,netdev=net0,romfile=
```

安装完成后重启虚拟机，安装过程中加密了虚拟机的数据分区/dev/sda3，接下来加密启动分区/dev/sda2。
启动后在虚拟机中使用scp命令将主机中的文件拷贝到虚拟机，这里假设主机的用户名为test，IP地址为192.168.122.1。

```
scp test@192.168.122.1:/opt/hygon/csv/setup-encrypt-kylin.sh  ./
sudo chmod +x setup-encrypt-kylin.sh
sudo ./setup-encrypt-kylin.sh
```

### 使用加密的镜像启动CSV虚拟机

disk\_encryption.sh默认使用Encpasswd0,如果密码正确，虚拟机会正常启动，否则会提示输入密码。

```
cd /opt/hygon/csv
# 示例中是启动csv虚拟机加密镜像
# 启动csv2虚拟机加密镜像 方法为sudo ./disk_encryption.sh csv2
# 启动csv3虚拟机加密镜像 方法为sudo ./disk_encryption.sh csv3，Kylin-Server-V10-SP3-2403 目前不支持csv3 磁盘加密启动
sudo ./disk_encryption.sh
```

vncviewer 0.0.0.0:1 登录虚拟机看虚拟机能否正常启动

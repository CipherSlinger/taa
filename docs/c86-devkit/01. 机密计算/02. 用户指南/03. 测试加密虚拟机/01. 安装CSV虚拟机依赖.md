## 准备虚拟机

客户根据需要选择对应的虚拟机，通常选择和主机配套的虚拟机,虚拟机root账号的登录密码为root。

- AnolisOS-8.10-x86\_64-ANCK.qcow2

```
wget -c https://download.sourcefind.cn:65024/directlink/8/c86-devkit/previous-release/csv/AnolisOS-8.10-x86_64-ANCK.qcow2 -O /opt/hygon/csv/vm.qcow2
```

- openEuler-24.03-LTS-x86\_64.qcow2

```
wget -c https://download.sourcefind.cn:65024/directlink/8/c86-devkit/previous-release/csv/openEuler-24.03-LTS-x86_64.qcow2 -O /opt/hygon/csv/vm.qcow2
```

- 由于商业版权问题，不能直接提供麒麟测试的虚拟机镜像，这里提供ISO制作虚拟机镜像的方法

```
cd /opt/hygon/csv/
# 将Kylin-Server-V10-SP3-2403-Release-20240426-X86_64.iso 镜像放到当前目录下
qemu-img create -f qcow2 vm.qcow2 50g
sudo qemu-system-x86_64 -enable-kvm -cpu host -smp 4 -m 4096 -drive if=pflash,format=raw,unit=0,file=/opt/hygon/csv/OVMF_CODE.fd,readonly=on -hda /opt/hygon/csv/vm.qcow2 -boot d -cdrom ./Kylin-Server-V10-SP3-2403-Release-20240426-X86_64.iso -vnc 0.0.0.0:1 -netdev bridge,br=virbr0,id=net0 -device virtio-net-pci,netdev=net0,romfile=
```

通过vnc 登录进行安装，命令为vncviewer IP:1，其中IP 为安装虚拟机镜像的主机的IP地址。
安装后重启虚拟机，在虚拟机中执行

```
# 更新虚拟机内核到最新版本
yum update -y kernel
# 打开虚拟机的串口
grubby --update-kernel=$(grubby --default-kernel) --args="console=ttyS0,115200n8 console=tty0"
```

如果客户使用自己定制的虚拟机，且不确定虚拟机中的内核是否支持CSV完整功能，请参考[软件编译安装 - 内核安装章节](<../01. 环境部署/04. 软件编译安装.md#内核安装>)更新虚拟机内核。

安装虚拟机内核可以用下面命令启动虚拟机，然后在虚拟机中安装内核

```
sudo qemu-system-x86_64 -name csv-vm --enable-kvm -cpu host -m 6114 -hda /opt/hygon/csv/vm.qcow2 -drive if=pflash,format=raw,unit=0,file=/opt/hygon/csv/OVMF_CODE.fd,readonly=on -qmp tcp:127.0.0.1:2222,server,nowait -vnc 0.0.0.0:0 -netdev bridge,br=virbr0,id=net0 -device virtio-net-pci,netdev=net0,romfile= -nographic
```

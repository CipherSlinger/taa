# 硬件要求

- 架构：C86
- CPU: Hygon C86-4G及以上
- 内存：8GB以上

# 软件要求

- 操作系统：Ubuntu 18.04、Ubuntu 22.04、CentOS 8.5、SUGON OS 8.5、SUGON OS 8.9、Rocky Linux 9.5、Kylin V10，以及 Anolis OS 8.9（不支持 32 位操作系统）
- glibc版本：2.17以上
- libstdc++版本：6及以上

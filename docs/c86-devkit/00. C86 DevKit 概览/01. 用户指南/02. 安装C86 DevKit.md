## 获取软件包

> **注：机密计算测试不需要文档上的步骤**

获取软件包方式：
在[c86-devkit下载网站](https://download.sourcefind.cn:65024/8/main/c86-devkit/latest) 选择  `c86-devkit_{version}.tar.gz` 进行下载。

## 校验完整性

```bash
wget https://download.sourcefind.cn:65024/directlink/8/c86-devkit/latest/c86-devkit_{version}.beta.tar.gz
wget https://download.sourcefind.cn:65024/directlink/8/c86-devkit/latest/c86-devkit_{version}.beta.tar.gz.sha256
sha256sum -c c86-devkit_{version}.beta.tar.gz.sha256
```

## 解压压缩包

```bash
tar -zxvf c86-devkit_{version}.beta.tar.gz
```

解压后，目录结构如下：

```bash
c86-devkit /
├── install.sh
├── payload/
│   ├── hag
│   ├── *.tar.gz
│   ├── *.deb
│   └── *.rpm
├── README.md
└── script/
    ├── modulefiles-setup.sh
    ├── setvars.sh
    ├── uninstall.sh
    └── unsetvars.sh
```

## 一键部署

**注意事项**

   - 请检查系统中是否已有其他版本的 Hygon HPC 工具链或相关组件安装在 `/opt/hygon` 或其他路径，以避免路径冲突或环境变量覆盖。
   - 安装前建议备份已有组件或安装目录，以防覆盖导致原有环境不可用。
   - 确认系统依赖库版本符合要求满足版本要求，否则可能导致运行异常或软件包无法正常使用。

### 默认安装方式

默认情况下，payload中的包会被安装到 `/opt/hygon/` 目录路径下（需要root权限）：

```bash
sudo ./install.sh
```

### 定制化安装方式

自定义安装支持 `--install-dir` 参数，用于指定安装目录。
或直接以普通用户执行install脚本，在交互界面输入自定义安装路径。

```bash
bash install.sh --install-dir /path/to/install
```

## 设置环境变量

### setenv模式

安装完成后执行：

```bash
    source /path/to/install/setvars.sh
```

根据提示选择hcc或hgcc编译器、 hjdk-8或hjdk-17：

```bash
    source /path/to/install/setvars.sh hcc hjdk-8
```

```bash
    source /path/to/install/setvars.sh hgcc hjdk-17
```

验证：

```bash
    gcc -v
    clang -v
    mpirun -V
    java --version
```

去除环境变量：

```bash
    bash /path/to/install/unsetvars.sh
```

此脚本仅撤销 C86 DevKit 添加的环境变量，不会影响系统默认 gcc/clang/java

### 使用environment-modules

*为了更有力的支持多版本环境和模块的调试，软件包支持借助module命令模块化管理组件，请预先自行安装environment-modules*

软件包安装完成后执行：

```bash
    bash /path/to/install/modulefile-setup.sh
```

脚本将会：

- 自动创建 modulefiles 目录

- 根据已安装的组件生成对应模块文件

生成module文件以后，需要先让环境模块识别：

```bash
    module use /path/to/install/modulefiles
```

加载对应模块：

```bash
    module load hcc
    module load hgcc
```

卸载已加载模块：

```bash
    module unload hcc
    module unload hgcc
```

也可以使用下面命令查看已注册或可用的组件：

```bash
    module avail
```

卸载所有已加载的模块：

```bash
    module purge
```

模块加载后可验证：

```bash
    gcc -v
    clang -v
    mpicc -V
```

### 卸载

使用以下提供的卸载脚本可卸载掉已安装的软件包：

```bash
    sudo bash /path/to/install/uninstall.sh
```

`uninstall.sh` 会删除 `/path/to/install/` 下所有由本工具包安装的内容。

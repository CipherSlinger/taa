# Paddle 用户指南

## 1. 简介

PaddlePaddle（Parallel Distributed Deep Learning）是百度自主研发、功能丰富、性能优异的开源深度学习平台，广泛应用于自然语言处理、计算机视觉、推荐系统等领域。Paddle 支持多种硬件平台和分布式训练，适配 Hygon C86 平台，助力 AI 业务高效部署。

## 2. 环境要求

**硬件要求：**

- Hygon C86-4G 及以上服务器

**软件要求：**

- 操作系统：
    * Ubuntu 20.04（CUDA11.8-12.9）
    * Ubuntu 22.04 (CUDA 11.8 - 12.9)
    * Ubuntu 24.04 (CUDA 11.8 - 12.9)
- Python 3.9 及以上
- GCC 8.5 及以上
- paddlepaddlev3.3.0及以上
- CUDA/cuDNN（如需 GPU 支持）

## 3. 安装

当前paddle官方并未给出针对Hygon-HML后端的发行wheel，需要手工从源码编译获取。以下以python3.9为例展示安装过程。

### 3.1 环境变量设置

```bash
conda create -n paddle_env python=3.9
conda activate paddle_env
#找到并设置python-lib路径
find `dirname $(dirname $(which python3))` -name "libpython3.so"
export PYTHON_LIBRARY=[python-lib-path]
export PATH=[python-lib-path]:$PATH

#找到并设置python-include路径
find `dirname $(dirname $(which python3))`/include -name "python3.9"
export PYTHON_INCLUDE_DIRS=[python-include-path]
```

```bash
#设置编译paddle相关依赖
pip install patchelf
pip isntall -r python/requirements.txt
```

### 3.2 源码编译

```bash
git clone https://github.com/PaddlePaddle/Paddle.git
cd Paddle
# 推荐使用 Docker 构建环境，或手动安装依赖
mkdir build && cd build
cmake .. -DPY_VERSION=3.9 -DPYTHON_INCLUDE_DIR=${PYTHON_INCLUDE_DIRS} -DPYTHON_LIBRARY=${PYTHON_LIBRARY} -DWITH_MKL=OFF -DWITH_HML=ON
make -j$(nproc)
```

### 3.3 安装 Paddle

```bash
#此时在paddle/build目录下
pip install --force-reinstall python/dist/paddlepaddle-*.whl
```

使用下述命令确认安装成功

```bash
python3 -c "import paddle; print(paddle.__version__)"
```

## 6. 常见问题与排查

- **依赖冲突**：建议使用conda等虚拟环境，避免与系统包冲突。
- **性能问题**：确认已开启多线程和 MKL 优化，或参考官方文档调整参数。

# 海光平台优化版 DPDK 示例程序使用说明

## 1. 简介

海光平台优化版 DPDK 示例程序基于公版 DPDK v23.11.5，针对海光处理器的架构特点，对 L3fwd、testpmd、mlx5 PMD、vhost及 `rte_memcpy` 等关键模块进行了性能优化。

优化版主要采用软件预取（Software Prefetch）、循环展开（Loop Unrolling）、循环融合（Loop Fusion）以及避免跨 Cache Line 拷贝等软件优化技术，在保持公版 DPDK API 和基本功能兼容的基础上，进一步提升海光平台搭配 NVIDIA ConnectX 系列网卡时，典型数据包处理场景下的单核性能和吞吐能力。

本文档介绍海光平台优化版 DPDK 示例程序的获取、安装及运行方法。DPDK 简介、测试环境准备及系统配置请参考前篇《海光平台DPDK部署与性能优化指南》。

## 2. 获取安装包

请访问以下地址下载海光平台优化版 DPDK 示例程序安装包：

[https://download.sourcefind.cn:65024/8/main/c86-devkit/latest/network](https://download.sourcefind.cn:65024/8/main/c86-devkit/latest/network)

## 3. 安装

下载完成后，使用以下命令将安装包解压至 `/opt/hygon` 目录：

```bash
sudo tar -xf "$package" -C /opt/hygon
```

其中，`$package` 为下载的安装包文件路径。

安装包包含以下两个目录：

- **`bin/`**：包含海光优化版 DPDK 示例程序 `dpdk-l3fwd` 和 `dpdk-testpmd`。
- **`lib/`**：包含 `libcrypto.so.3`和`libpcap.so.1`运行时依赖库。

## 4. 应用示例

本节介绍海光平台优化版 DPDK 在不同应用场景下的运行方法，测试报文长度为 64 Bytes ,69 Bytes和 1518 Bytes。

### 4.1 L3fwd 单核双队列

使用单个 CPU 物理核心处理两个 RX Queue，运行命令如下：

```bash
sudo /opt/hygon/dpdk/bin/dpdk-l3fwd -a 95:00.0 -l 176 -- -p 0x1 --config="(0,0,176),(0,1,176)" -P
```

### 4.2 testpmd IO Forward 单核三队列

使用单个 CPU 物理核心处理三个 RX/TX Queue，采用 IO Forwarding 模式进行数据包转发。

```bash
sudo /opt/hygon/dpdk/bin/dpdk-testpmd -l 176-177 -a 95:00.0 -- --burst=256 --txd=1024 --rxd=1024 --mbcache=512 --rxq=3 --txq=3 --nb-cores=1 --forward-mode=io -a -i
```

### 4.3 testpmd MAC Forward 单核双队列

使用单个 CPU 物理核心处理两个 RX/TX Queue，采用 MAC Forwarding 模式进行数据包转发。

```bash
sudo /opt/hygon/dpdk/bin/dpdk-testpmd -l 176-177 -a 95:00.0 -- --burst=256 --txd=1024 --rxd=1024 --mbcache=512 --rxq=2 --txq=2 --nb-cores=1 --forward-mode=mac -a -i
```

### 4.4 L3fwd 多核多队列（开启 mlx5 PMD MPRQ）

使用八个 CPU 物理核心分别处理八个 RX Queue，并开启 mlx5 PMD 的 Multi-Packet Receive Queue（MPRQ）特性。

```bash
sudo /opt/hygon/dpdk/bin/dpdk-l3fwd -a 95:00.0,txq_inline_mpw=128,mprq_en=1,rxqs_min_mprq=1,mprq_log_stride_num=9,rxq_pkt_pad_en=1 -l 176-183 -- -p 0x1 --config="(0,0,176),(0,1,177),(0,2,178),(0,3,179),(0,4,180),(0,5,181),(0,6,182),(0,7,183)" -P
```

### 4.5 testpmd MAC Forward 物理网卡与 vhost-user 接口间转发

启动两个 testpmd 进程，分别在物理网卡所在 NUMA 节点和另一 NUMA 节点运行 vhost-user 侧与 virtio-user 侧，每个进程使用一个CPU 物理核心进行 MAC Forwarding 模式数据包转发。

```bash
sudo /opt/hygon/dpdk/bin/dpdk-testpmd -l 96-97  --vdev 'net_virtio_user0,mac=00:11:22:33:44:55,path=/tmp/vhost-user,queues=1,server=1,queue_size=1024'  --file-prefix="virtio" --no-pci -- -i --forward-mode=mac -a --burst=64

sudo /opt/hygon/dpdk/bin/dpdk-testpmd -l 176-177  --file-prefix="vhost" --vdev 'net_vhost0,iface=/tmp/vhost-user,queues=1,client=1' -a 0000:95:00.0  -- -i --forward-mode=mac --nb-cores=1 -a --txd=1024 --rxd=1024 --burst=64
```

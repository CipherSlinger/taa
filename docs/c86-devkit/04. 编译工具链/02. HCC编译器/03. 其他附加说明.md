# 其他附加说明

> 上游社区与商业OS合入总结及计划

## 1. 上游社区开源计划

- 海光 CPU 识别与调度模型( `c86-4g-m4/m6/m7/m8` 命名、X86 调度模型)已在 LLVM 开源主线中落地(随上游新版本发布)
- 开源与微架构相关的优化

## 2. 商业 OS 合入计划

暂无可见的商业 OS 合入记录;当前通过官方渠道(光合社区)以安装包方式提供并已完成适配验证,后续如有计划，将会及时补充。

## 3. 内部漏洞扫描

### 3.1. 测试范围与对象

- 交付物:编译器安装包(tar.gz / rpm / deb)及随附组件(运行时库、工具链);
- 依赖与第三方组件:随附第三方组件(以发布包实际内容为准)

### 3.2. 初步结论

截至本次流水线测试,交付物未发现未处置的严重/高危漏洞。

## 4. 用户许可协议

- 协议名称《海光C86-DevKit开发套件用户许可协议》
- 光合开发者社区([download.sourcefind.cn](http://download.sourcefind.cn),c86-devkit 目录)公示,随包提供

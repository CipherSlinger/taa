# HCC的安装和使用

## 1. 环境依赖

### 支持架构

C86

### 支持系统

CentOS-8.0、Ubuntu-18.04、Ubuntu-22.04、openEuler-24.03、KylinOS-v11

### 软件依赖

| Package Name | Version(s)      | Notes                                                        |
| ------------ | --------------- | ------------------------------------------------------------ |
| libstdc++    | 3.4.19 or later | GNU Standard C++ Library                                     |
| glibc        | 2.17 or later   | 2.31 or later is better which could recognize Hygon Platform |

## 2. 安装方式

### 编译器下载

请访问以下地址下载安装包：https://download.sourcefind.cn:65024/8/main/c86-devkit/latest/compiler/hcc

```bash
wget https://download.sourcefind.cn:65024/8/main/c86-devkit/latest/compiler/hgcc/hcc-{version}.x86_64.tar.gz
```

### 编译器安装

```bash
sudo tar -zvxf hcc-{version}.x86_64.tar.gz
```

### 环境变量设置

```bash
cd /path/to/install/hgcc
source setenv_hygoncc.sh
```

**说明**，示例中的目录仅供参考，请以实际的安装路径为准。

#### 使用HygonCC编译c/c++程序

```
$ clang [command line flags] hello.c -o hello

$ ./hello

$ clang++ [command line flags] hello.cc -o hello

$ ./hello
```

#### 使用HygonCC编译Fortran程序

```
$ flang [command line flags] hello.f90 -o hello

$ ./hello
```

#### 指定链接器

链接时默认使用的是系统下的 ld 链接器，如需使用LLVM 的lld 链接器，可以使用`-fuse-ld`指定，如下：

```
$ clang [command line flags] -fuse-ld=lld hello.c -o hello

$ ./hello
```

### 配置运行库

- 64 位运行时库

`export LD_LIBRARY_PATH=<compdir>/lib:$LD_LIBRARY_PATH`

- 32 位运行时库

`export LD_LIBRARY_PATH=<compdir>/lib32:$LD_LIBRARY_PATH`

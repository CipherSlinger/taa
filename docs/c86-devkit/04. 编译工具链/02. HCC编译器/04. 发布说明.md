# 发布说明

## 1. 版本信息

### 1.1. 本次发布概要

- 产品名称:HygonCC 编译器(hcc)
- 版本号:2.13.0
- 构建版本: hcc-16.0.4-260909.4.x86\_64.tar.gz
- 上游基线:LLVM / Clang 16.0.4
- 目标架构:海光 C86(兼容 x86-64)
- 获取方式:光合开发者社区( [c86.sourcefind.cn](http://c86.sourcefind.cn) )提供 tar.gz 压缩包;另提供 rpm / deb 安装包
- 社区渠道现状(参考):光合社区 latest 渠道当前为 Beta 构建(c86-devkit\_20260918.beta.tar.gz、hcc-16.0.4-260909.4.x86\_64.tar.gz),附 Beta 标注"仅限非生产环境使用"
- 许可与声明：本软件适用《海光C86-DevKit开发套件用户许可协议》与《免责声明》(随包提供,并于光合开发者社区公布)

### 1.2. 发布内容构成

- 编译器二进制包(tar.gz / rpm / deb)
- 产品文档集:产品概述、安装指南、入门指南、编译选项参考手册、安全能力增强说明、PGO 与 BOLT 用户指南，随版本交付

## 2. 新增特性

### 2.1. 编译优化能力增强

本版围绕海光平台应用性能完成多项重点优化,覆盖多级尾部向量化、GROMACS 软件预取与 Gather 指令拆分、WRF 向量化与 OpenMP、LAMMPS、SPADES 及 OpenMP 互斥消除等方向,相关课题在典型算例上均取得明显性能提升。

### 2.2. 工具链与生态完善

- PGO / BOLT 全流程支持:插桩式 PGO 与 BOLT 布局优化的完整使用流程与注意事项
- VML 向量数学库集成: `-fveclib=HVML` 及链接口径 `-lvml-hg`
- 光合开发者社区分发:支持开源社区渠道获取

## 3. 缺陷修复

本版修复的问题涵盖:编译报错、编译卡死与段错误等编译稳定性问题;与上游基线编译器执行输出不一致的问题;部分场景的性能回退问题;前端/中端优化的正确性问题;数学库与链接相关的兼容性问题;以及回归测试用例的适配修复等。

## 4. 已知问题及规避方式

| # | 现象 | 规避方法 |
|---|---|---|
| 1 | 海光平台不支持 LBR(硬件分支采样) | 使用插桩式 PGO(流程见《PGO与BOLT用户指南》) |
| 2 | 直接使用 -flto 报相关库缺失 | 配置 -fuse-ld=lld 一同使用 |

## 6. 调整项与废弃项

- LTO 链接要求明确:`-flto` 需配合 `-fuse-ld=lld` 使用
- 数学库链接口径统一:统一使用 `-lvml-hg`(`libhvml.so` 为库本体;`libvml-hg.so`、`libhygonvml.so` 为兼容软链)
- 微架构命名迁移:`c86-4g-m4/m6/m7/m8` 为开源社区新命名

## 7. 生命周期信息

- 支持范围:本版本自正式发布之日起提供维护支持;
- 缺陷修复窗口:在后续两个版本周期内提供缺陷修复与小版本更新;
- 升级路径:建议按版本序列升级,升级操作见《安装指南》

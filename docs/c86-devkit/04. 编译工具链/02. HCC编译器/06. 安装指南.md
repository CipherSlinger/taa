# 02-安装指南

| 项目 | 内容 |
|---|---|
| 文档名称 | HygonCC 编译器安装指南 |
| 文档版本 | V1.0 |
| 目标读者 | 使用海光 C86 平台、需要部署与使用 HygonCC 编译器的客户、生态伙伴及集成商 |

**说明：本文档介绍 HygonCC 编译器的安装前置要求、多种安装方式、环境变量初始化脚本的用法，以及多版本共存与切换方法。文中命令以 root 用户执行为例**

## 1. 安装前准备

### 1.1. 硬件要求

| 项目 | 要求 |
|---|---|
| 处理器架构 | 海光 C86 处理器(x86\_64 架构) |
| SIMD 支持 | 支持 AVX2 / AVX-512 等 SIMD 指令集(配合 -march 使用详见产品概述) |
| 磁盘空间 | 按安装包实际大小预留解压与多版本并存空间(建议预留数个 GB) |

### 1.2. 操作系统要求

| 操作系统 | 支持版本 |
|---|---|
| CentOS | 8.0 |
| Ubuntu | 18.04 / 22.04 |
| openEuler | 24.03 |
| KylinOS | v11 |

### 1.3. 软件依赖

| 软件依赖 | 版本要求 | 说明 |
|---|---|---|
| libstdc++ | 3.4.19 或更高版本 | GNU Standard C++ Library |
| glibc | 2.17 或更高版本 | 建议 2.31 或更高版本，可完整识别海光平台特性 |

安装前可用以下命令检查依赖版本：

- 检查 glibc 版本
- 检查 libstdc++ 是否包含所需版本符号(3.4.19)

ldd --version strings /usr/lib64/libstdc++.so.6 | grep GLIBCXX\_3.4.19

> 注意：若 glibc 版本过低，运行编译器时会报类似 `version 'GLIBC_2.xx' not found` 的错误，请升级系统或在满足要求的系统上安装。

### 1.4. 权限说明

- 使用 root 用户安装可将编译器安装至 /opt/hygon 等系统目录，供全体用户使用；
- 使用普通用户安装时，请将安装目录指定到用户有写权限的路径(压缩包方式天然支持自定义路径，见 3.1 节)；
- 若需全体普通用户使用，安装完成后建议对安装目录执行 chmod -R 755 \<安装目录\>。

## 2. 获取安装包

### 2.1. 光合开发者社区下载

- 访问光合开发者社区(光合组织官方开发者社区)：https://c86.sourcefind.cn/
- 进入 C86 Devkit → compiler → hcc 目录，下载对应版本的 hcc-{version}.x86\_64.tar.gz 压缩包；
- 也可通过命令行直接下载：

```
curl -L -O https://download.sourcefind.cn:65024/file/8/c86-devkit/latest/compiler/hcc/hcc-{version}.x86_64.tar.gz
# or
wget https://download.sourcefind.cn:65024/8/main/c86-devkit/latest/compiler/hcc/hcc-{version}.x86_64.tar.gz
```

> 二进制下载目录:[https://download.sourcefind.cn:65024/8/main/](https://download.sourcefind.cn:65024/8/main/)。具体版本号以网站实际发布的文件名称为准。

### 2.2. 源码获取

通过公司 Gerrit 获取源码(需公司账号，clone 后切换至 develop 分支)：

## 3. 安装方式

### 3.1. 压缩包安装

压缩包方式支持自定义安装路径、天然支持多版本并存，是官方推荐方式。

1. 校验完整性(可选，以网站公布的校验值为准)：# 与下载页面公布的 SHA256 值比对，一致则说明包完整

```
sha256sum hcc-{version}.x86_64.tar.gz
```

2. 解压安装到目标目录(这里以 **/opt/hygon/hcc/2.12.0**为例)：

```
mkdir -p /opt/hygon/hcc/2.12.0
tar -zxvf hcc-{version}.x86_64.tar.gz -C /opt/hygon/hcc/2.12.0
```

> 解压后目录包含编译器命令(`bin`)、运行时库(`lib`/`lib32`)及环境初始化脚本 `setenv_hcc.sh`(以包内实际内容为准)。如需自定义安装路径，将上述目录替换为任意有写权限的路径即可。

3. 授权全体用户使用(可选)：

```
chmod -R 755 /opt/hygon/hcc/{version}
```

4. 加载环境变量：

```
source /opt/hygon/hcc/{version}/setenv_hcc.sh
```

5. 设置默认编译器(可选，建议执行)：

```
export CC=clang
export CXX=clang++
export FC=flang
```

6. 验证安装：

```
clang -v
# clang version 16.0.4
```

### 3.2. RPM软件包安装

适用于 CentOS / openEuler / KylinOS 等使用 RPM 包管理器的系统。rpm 包默认安装路径为 `/opt/hygon。`

\# 方式一:rpm 命令安装

```
sudo rpm -ivh hcc-{version}.rpm
```

\# 方式二:dnf / yum 本地包安装(自动处理依赖关系)

```
sudo dnf localinstall hcc-{version}.rpm     # openEuler 24.03、CentOS 8（dnf）
sudo yum localinstall hcc-{version}.rpm     # yum
```

安装后加载环境并验证：

```
source setenv_hcc.sh
clang -v
```

卸载：

`sudo rpm -e <rpm 包名> # rpm -qa | grep hcc 可查询包名`<br>`sudo dnf remove <rpm 包名> # dnf 安装时使用`<br>`sudo yum remove <rpm 包名> # yum 安装时使用`

### 3.3. DEB软件包安装

适用于 Ubuntu / Debian 系统。deb 包默认安装路径为 `/opt/hygon。`

\# 方式一:dpkg 命令安装

```
sudo dpkg -i hcc-{version}.deb
```

\# 方式二:apt 本地包安装(自动处理依赖关系)

```
sudo apt install ./hcc-{version}.deb
```

安装后加载环境并验证：

```
source setenv_hcc.sh
clang -v
```

卸载：

`sudo dpkg -r <deb 包名> # dpkg -l | grep hcc 可查询包名`<br>`sudo apt remove <deb 包名> # apt 安装时使用`

### 3.4. 在线源安装

以下自建源内容为通用 Linux 做法：

自建 yum / dnf 本地源：

```
# 1. 在源服务器上创建仓库目录并放入 rpm 包
mkdir -p /srv/repo/hcc
cp hcc-{version}.rpm /srv/repo/hcc/

# 2. 生成仓库元数据
dnf install -y createrepo        # 或 yum install -y createrepo
createrepo /srv/repo/hcc

# 3. 在客户机上配置 repo 文件(/etc/yum.repos.d/hcc.repo)
cat > /etc/yum.repos.d/hcc.repo << EOF
[hcc]
name=HygonCC Compiler Repository
baseurl=http://<源服务器地址>/repo/hcc
enabled=1
gpgcheck=0
EOF

# 4. 安装/更新
dnf install hcc-{version}          # 或 yum install hcc-{version}
dnf update hcc                   # 或 yum update hcc
```

自建 apt 本地源：

```
# 1. 在源服务器上创建仓库目录并放入 deb 包
mkdir -p /srv/repo/hcc
cp hcc-{version}.deb /srv/repo/hcc/

# 2. 生成软件包索引
apt install -y dpkg-dev
dpkg-scanpackages /srv/repo/hcc | gzip > /srv/repo/hcc/Packages.gz

# 3. 在客户机上配置源(/etc/apt/sources.list.d/hcc.list)
echo "deb [trusted=yes] http://<源服务器地址>/repo/hcc ./" > /etc/apt/sources.list.d/hcc.list

# 4. 安装/更新
apt update
apt install hcc-{version}
```

## 4. 环境变量初始化脚本用法

HygonCC 安装包内提供环境变量初始化脚本，用于一键配置编译器所需的 PATH、LD\_LIBRARY\_PATH 等环境变量。脚本命名规则为 setenv\_\<编译器\>.sh，HygonCC 对应 setenv\_hcc.sh；历史版本中setenv\_hygoncc.sh，以包内实际脚本名称为准。

### 4.1. 基本用法

环境脚本必须使用 `source` 加载(直接执行不会生效，因为环境变量只对当前 shell 生效)：

\# 正确:source 加载(或 . 加载)

```
source /opt/hygon/hcc/{version}/setenv_hcc.sh
```

\# 等价写法

```
. /opt/hygon/hcc/{version}/setenv_hcc.sh
```

\# 错误:直接执行,退出后环境变量丢失

```
# /opt/hygon/hcc/{version}/setenv_hcc.sh
```

> 加载效果仅对当前 shell 会话有效。每个新打开的终端都需要重新 source 一次：如需永久生效，见下面章节说明。

### 4.2. 主要配置说明

| 配置项 | 作用 |
|---|---|
| PATH | 将编译器的 bin 目录置于 PATH 前部，使 clang / clang++ / flang 等命令可用 |
| LD\_LIBRARY\_PATH | 指向运行时库目录，保证编译产物与编译器自身的动态库能被找到 |
| 其他(视脚本实现) | 可能包含 MANPATH、CPATH 等辅助配置 |

### 4.3. 永久生效配置

单用户生效(追加到 `~/.bashrc`)：

```
echo 'source /opt/hygon/hcc/{version}/setenv_hcc.sh' >> ~/.bashrc
echo 'export CC=clang'  >> ~/.bashrc
echo 'export CXX=clang++' >> ~/.bashrc
echo 'export FC=flang'  >> ~/.bashrc
```

全体用户生效(root 创建 `/etc/profile.d/hcc.sh`)：

```
cat > /etc/profile.d/hcc.sh << EOF
source /opt/hygon/hcc/{version}/setenv_hcc.sh
export CC=clang
export CXX=clang++
export FC=flang
EOF
```

### 4.4. hash缓存注意事项（可选）

如果系统中还安装了其他版本的 LLVM/Clang 编译器，在 source 环境脚本之后建议立即执行：

```
hash -r
```

> 防止 `clang` 命令被 shell 的 hash 表缓存，导致调用到旧路径的编译器

### 4.5. 套件级脚本(DevKit / HpcKit)

如用户安装的是完整的 C86 DevKit(包含 hgcc/hcc/HJDK 等组件套件)，则使用套件级环境脚本与模块文件：

- 环境脚本: setvars.sh (配置套件内所有组件的环境变量)；
- 模块文件：随包提供 modulefiles-setup.sh，可为各组件生成 Environment Modules 模块文件。

## 5. 多版本共存与切换

HygonCC 采用按版本分目录的安装布局，不同版本安装到各自目录，互不影响，天然支持多版本共存。

```
/opt/hygon/hcc/
├── 2.11.0/          # 版本 2.11.0(含 setenv_hcc.sh)
└── 2.12.0/          # 版本 2.12.0(含 setenv_hcc.sh)
```

### 5.1. 方式一:source 对应版本脚本切换(最直接)

```
# 2.12.0
source /opt/hygon/hcc/2.12.0/setenv_hcc.sh && hash -r
clang -v

# 2.11.0
source /opt/hygon/hcc/2.11.0/setenv_hcc.sh && hash -r
clang -v
```

### 5.2. 方式二:环境模块(Environment Modules)切换(集群推荐)

若系统安装了 Environment Modules，可参考如下方式为各版本建立模块文件(`/opt/hygon/hcc/modulefiles/2.12.0`)：

```
#%Module 1.0
module-whatis "HygonCC Compiler 2.12.0"
set root /opt/hygon/hcc/2.12.0
prepend-path PATH $root/bin
prepend-path LD_LIBRARY_PATH $root/lib
setenv CC clang
setenv CXX clang++
setenv FC flang
```

使用方式

```
module use /opt/hygon/hcc/modulefiles
module load hcc/2.12.0      # 加载指定版本
module switch hcc/2.11.0 hcc/2.12.0   # 切换版本
module list                  # 查看已加载模块
```

> C86 DevKit 套件自带的 `modulefiles-setup.sh` 可自动生成上述模块文件，优先使用套件提供的脚本

### 5.3. 切换注意事项

- 切换版本后务必执行 hash -r，避免 shell 命中旧命令路径缓存
- 注意 PATH 中编译器路径的顺序：优先级取决于靠前的路径，多个编译器并存时以实际 which clang 结果为准
- LD\_LIBRARY\_PATH 同样按顺序生效，切换后可用 echo $LD\_LIBRARY\_PATH 确认

## 6. 安装验证与常见问题

### 6.1. 安装验证

```
# 1.验证编译器版本
clang -v
clang++ --version
flang -v
# 预期输出包含海光版本标识,例如:
# clang version 16.0.4 (hcc 2.11.0-260402-4)

# 2.编译运行 C 程序
clang hello.c -o hello
./hello

# 3.编译运行 C++ 程序
clang++ hello.cpp -o hello
./hello

# 4.编译运行 Fortran 程序
flang hello.f90 -o hello
./hello
```

### 6.2. 常见问题

| 现象 | 原因与处理 |
|---|---|
| version 'GLIBC\_2.xx' not found | 系统 glibc 版本低于要求,请升级系统或在满足要求的系统上安装 |
| 运行时找不到动态库 | 确认已 source 环境脚本，或手动配置 LD\_LIBRARY\_PATH |
| undefined reference to | 建议使用 HygonCC 提供的标准库实现并检查链接参数 |
| clang 命令仍指向旧编译器 | 执行 hash -r 并检查 PATH 路径顺序 |
| 编译超大源码时 segmentation fault | ulimit -s 20000 或 ulimit -s unlimited |
| 使用 -Werror 后构建失败 | 用 -Wno-\<警告名\> 关闭对应告警 |

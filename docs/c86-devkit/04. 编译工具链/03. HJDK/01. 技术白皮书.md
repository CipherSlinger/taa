# HygonJDK技术概述

HygonJDK是基于OpenJDK构建的一款高性能的、可用于生产环境的OpenJDK发行版。HygonJDK是OpenJDK的下游，与Java SE标准兼容，目前支持Linux/x86\_64平台。

# HJDK 环境部署

## 1. 软硬件要求

**硬件要求：**

- Hygon C86

**软件要求：**

- GNU C Library (glibc) （\> 2.35）
- gcc（\>=10.3）

**已验证支持的操作系统包括：**
ubuntu 22.04

## 2. 安装

### HJDK下载

请访问以下地址下载安装包：https://download.sourcefind.cn:65024/8/main/c86-devkit/latest/compiler/hjdk

### HJDK安装

```bash
sudo tar -zvxf hjdk-{version}.x86_64.tar.gz
```

## 3 使用

### 设置环境变量

**HJDK-8：**

```bash
export JAVA_HOME=/path/to/install/hjdk-8
export PATH=$JAVA_HOME/bin:$PATH
```

**HJDK-17：**

```bash
export JAVA_HOME=/path/to/install/hjdk-17
export PATH=$JAVA_HOME/bin:$PATH
```

**验证：**

```
$ which java
$ java -version
```

### 使用已安装的HJDK

```
$ java test.java
$ ./test
```

### 删除环境变量

```
$ unset JAVA_HOME
```

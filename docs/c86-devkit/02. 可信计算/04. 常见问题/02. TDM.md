# TDM FAQ

#### Q: 使用TDM创建度量任务失败问题，返回0x15的错误码，但通过hag查看显示hgsc已导入

A: 请确认hag版本是否\>=1990，如果不是，请更新hag，然后重新导入HGSC。该问题为hag的BUG，在1990以上版本已修复。

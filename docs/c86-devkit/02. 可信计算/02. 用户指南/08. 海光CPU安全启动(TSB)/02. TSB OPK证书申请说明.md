# 一、OPK证书释义

海光 TSB OPK 证书（OEM Public Key Certificate）是海光颁发给整机厂商（OEM）的公钥证书，是开启海光 CPU TSB 可信安全启动的核心凭证，用于建立从 CPU 硬件信任根到 BIOS 固件的可信启动链。

# 二、OPK证书申请流程

（1）填写申请表，格式见附件一；

（2）准备json文件或者变更的json文件，json文件的格式见附件二；

（3）用公司授权邮箱发送json文件和申请表盖章扫描件至securitytech@hygon.cn；

（4）注意邮箱查收证书。

### 附件二：

**json文件格式示例如下（全英文字符，不支持中文字符）：**

```
"subject":"Owner=Platform Engineering, Product=ECS Server",
"userid":"ecs_bios_sign#1",
"pubkey_endian":"be",
"pubkey":
"b2476d776878bc00dca23cf27afec6d0e862438f1c6aa893306a55303dbc6f734510efd46830a57b5fc9e66b233f2d63f61b414e242b86c311e0f262e3866abc"
```

说明：

subject：证书主题，可以说明证书的用途、属主等，与申请表中保持一致。

> 注：主题可以用来支撑同一厂商不同类产品间实现隔离，不同主题证书不能混用。如后续更新该证书中公钥，需提供相同的证书主题。

userid：sm2用户id，最大支持32字节。

pubkey\_endian：sm2公钥端序，“be”表示大端，“le”表示小端。

> 注：一般使用openssl工具生成的sm2密钥默认是大端序。

pubkey：64字节 sm2公钥，对应OPK证书030h偏移处开始的32字节QX加32字节QY。

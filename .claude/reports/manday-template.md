# 人天统计模板

## 使用流程

1. 取当月提交：`git log --since=<月初> --until=<月末+1天> --date=short --pretty=format:'%ad %s'`
2. 按周切分区间（周一至周五；跨月首尾按实际工作日）。
3. 把提交按子系统归并成条目，一条对应一项可交付工作，不逐条罗列提交。
4. 给条目分配人天，以 **0.5 人天** 为最小单位。
5. 校验：每条之和 = 周标题人天 = 该周有提交的工作日数；各周之和 = 合计。

## 输出格式

```markdown
# <项目> <年> 年 <月> 月人天统计

统计范围：YYYY-MM-DD 至 YYYY-MM-DD 的仓库提交（共 N 条），按周次归并。
人天以 0.5 人天为最小单位；周内人天 = 该周有提交的工作日数。

## 第 N 周（MM.DD-MM.DD，X 人天）

1. <子系统名称>：<具体工作描述>（X 人天）
2. <子系统名称>：<具体工作描述>（X 人天）

...

## 合计

X 人天。
```

## 编写约定

- **粒度**：一条 = 一个子系统的一项可交付工作，描述控制在 30 字以内，冒号前写子系统，冒号后写做了什么。
- **单位**：只用 0.5 / 1.0 / 1.5 / 2.0 …，禁止 0.25、0.75 这类细分。
- **归并**：同一子系统的多次迭代（含 docs/test 提交）合并成一条，不按提交类型拆条。
- **周划分**：以周标题日期区间为准，区间内没有提交的日期不计人天。
- **排序**：按工作量从大到小，无固定顺序时按开发主线顺序。
- **措辞**：用动词短语描述产出（设计、实现、修复、对齐），不写过程细节和 IDE/工具偏好。

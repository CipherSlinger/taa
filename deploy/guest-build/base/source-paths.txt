# Facts about the fetched initrd that decide how TAA can be started in it,
# read on the same host the same day:
#   * it carries a root-level `init -> /sbin/init` symlink (and /usr/sbin/init is
#     the real 19 MB binary), so the kernel's ramdisk_execute_command default
#     /init succeeds and `init=` is dead config. Only `rdinit=` takes effect.
#   * it is built with systemd (usr/lib/systemd, rc?.d symlinks), so the wrapper
#     is inserted ahead of /sbin/init rather than replacing it.
#   * /dev is a tmpfs with no devtmpfs and no udev, so /dev/csv-guest has to be
#     created by hand before TAA can read its attestation report.

# 07-健康检查与接口验证

## Node API 健康检查

```bash
curl -i http://127.0.0.1:58996/api/v1/health
```

## Nginx 健康检查

```bash
curl -i http://127.0.0.1:8995/gateway/health
curl -i http://127.0.0.1:8995/api/v1/health
```

远程访问时把 `127.0.0.1` 替换为服务器 IP。

## 验证模型接口

```bash
curl -fsS -i http://127.0.0.1:8995/api/v1/models \
  -H "X-User-Id: <user-id>"
```

响应头应包含：

```text
X-Nginx-Route-Key: <user-id>
X-Upstream-Addr: <node-ip>:58996
```

## Worker GPU 检查

按实际容器名替换：

```bash
docker exec fhe-worker-a130-58996 nvidia-smi
```

8.62 示例：

```bash
docker exec fhe-worker-a62-58996 nvidia-smi
```

## 端口检查

```bash
ss -lntp | grep -E ':8995|:58996|:58998'
```

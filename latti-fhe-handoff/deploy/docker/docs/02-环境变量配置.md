# 02-环境变量配置

## 复制本机配置

```bash
cd /home/wuwm/prod-project/latti-client/deploy/docker

cp env/node.local.env.example env/node.local.env
```

`*.local.env` 是本机配置，不提交 Git。

## A130 示例

`env/node.local.env`：

```env
NODE_ID_OVERRIDE=A130
NODE_IP_OVERRIDE=192.168.3.130

API_PORT=58996
API_HOST_PORT=58996
LOCAL_REDIS_BIND_HOST=127.0.0.1
LOCAL_REDIS_HOST_PORT=58998
```

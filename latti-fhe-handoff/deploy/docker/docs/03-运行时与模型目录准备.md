# 03-运行时与模型目录准备

`third_party/latti-ai-runtime` 不在 Git 仓库中，需要单独准备。

## 默认目录

```text
/home/wuwm/prod-project/latti-client/third_party/latti-ai-runtime
```

至少需要包含：

```text
third_party/latti-ai-runtime/build/inference/lattisense/liblattisense.so
third_party/latti-ai-runtime/examples/<model-dir>/task/server
```

检查：

```bash
ls -lh third_party/latti-ai-runtime/build/inference/lattisense/liblattisense.so
ls -lh third_party/latti-ai-runtime/examples
```

## 自定义 runtime 路径

如果生产环境 runtime 不在项目目录中，在 `env/node.local.env` 设置：

```env
HOST_RUNTIME_DIR=/path/to/latti-ai-runtime
```

## 同步模型目录到 8.62

推荐只同步当前需要的模型目录，不同步整个 `third_party`：

```bash
cd /home/jiangsy/prod-project/latti-client

mkdir -p third_party/latti-ai-runtime/examples

rsync -avh --progress \
  wuwm@192.168.3.130:/home/wuwm/prod-project/latti-client/third_party/latti-ai-runtime/examples/<model-dir> \
  ./third_party/latti-ai-runtime/examples/
```

如果确认要让某个模型目录与 A130 完全一致，只对该模型目录使用 `--delete`：

```bash
rsync -avh --delete --progress \
  wuwm@192.168.3.130:/home/wuwm/prod-project/latti-client/third_party/latti-ai-runtime/examples/<model-dir> \
  /home/jiangsy/prod-project/latti-client/third_party/latti-ai-runtime/examples/
```

不要对整个 `third_party` 使用 `--delete`。

# 04-构建镜像

A130 是测试和构建机器；8.62 正式环境不执行 build。

## 什么时候需要 build

需要 build：

```text
server/api_server.py
server/worker.py
server/config/
server/routers/
server/stores/
server/helpers/
server/worker_runtime/
server/Dockerfile
server/requirements.txt
```

不需要 build，通常只重建或重启容器：

```text
env/node.local.env
deploy/docker/configs/
third_party/latti-ai-runtime
模型文件
nginx.conf
```

## A130 构建

```bash
cd /home/wuwm/prod-project/latti-client/deploy/docker

./scripts/run-node.sh up -d --build
./scripts/run-node.sh ps
```

确认镜像：

```bash
docker images | grep -E 'redis|latti-server'
```

期望包含：

```text
redis                 7-alpine
latti/latti-server    latest
```

## 8.62 禁止 build

8.62 不执行：

```bash
./scripts/run-node.sh up -d --build
./scripts/run-stack.sh rebuild
```

8.62 应使用 A130 打包好的镜像，见 [09-镜像构建与离线分发](09-镜像构建与离线分发.md)。

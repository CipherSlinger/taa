# 10-8.62正式环境部署

8.62 是正式环境，原则上只导入 A130 构建好的镜像，不在本机 build。

## 进入项目目录

```bash
cd /home/jiangsy/prod-project/latti-client
```

如果实际路径不同，按实际路径替换。

## 拉取代码

```bash
git fetch origin
git checkout feat/end-to-end
git pull --rebase origin feat/end-to-end
```

## 配置环境变量

```bash
cd deploy/docker

cp env/node.local.env.example env/node.local.env
```

参考 [02-环境变量配置](02-环境变量配置.md) 写入 8.62 的 IP 和端口。

## 导入镜像

先从 A130 获取镜像包，见 [09-镜像构建与离线分发](09-镜像构建与离线分发.md)。

```bash
cd /home/jiangsy/prod-project/latti-client/deploy/docker

docker load -i latti-docker-images.tar.gz
```

## 准备 runtime 和模型目录

见 [03-运行时与模型目录准备](03-运行时与模型目录准备.md)。

## 启动服务

启动 Node：

```bash
./scripts/run-node.sh up -d
```

如果只是更新镜像后重建容器：

```bash
./scripts/run-node.sh up -d --force-recreate fhe-api fhe-worker
```

## 启动 Nginx

如果 8.62 是入口服务器，使用 `nginx-8.62.conf`：

```bash
NGINX_CONF=/home/jiangsy/prod-project/latti-client/nginx-8.62.conf

sudo nginx -t -c "$NGINX_CONF"
sudo nginx -c "$NGINX_CONF"
```

`nginx -c` 只用于首次启动项目 Nginx；如果已经启动，后续修改配置只执行：

```bash
sudo nginx -t -c "$NGINX_CONF"
sudo nginx -s reload -c "$NGINX_CONF"
```

完整操作和 pid 恢复见 [06-Nginx配置与启动](06-Nginx配置与启动.md)。

## 验证

```bash
curl -i http://127.0.0.1:58996/api/v1/health
curl -i http://127.0.0.1:8995/api/v1/health
```

完整验证见 [07-健康检查与接口验证](07-健康检查与接口验证.md)。

## 禁止命令

8.62 不执行：

```bash
./scripts/run-node.sh up -d --build
./scripts/run-stack.sh rebuild
```

# 05-启动与停止服务

## 进入目录

```bash
cd /home/wuwm/prod-project/latti-client/deploy/docker
```

其他服务器替换为实际项目路径。

## 启动 Node

```bash
./scripts/run-node.sh up -d
```

启动后应包含：

```text
fhe-redis-<node-instance>
fhe-api-<node-instance>
fhe-worker-<node-instance>
```

## 重启 Node

```bash
./scripts/run-node.sh restart
```

## 重建容器但不 build

配置、模型或 runtime 变更后通常执行：

```bash
./scripts/run-node.sh up -d --force-recreate fhe-api fhe-worker
```

## 停止 Node

```bash
./scripts/run-node.sh stop
```

## 删除容器和网络但保留数据

```bash
./scripts/run-node.sh down
```

不要执行 `down -v`，除非明确要删除持久化数据。

## 组合入口

```bash
./scripts/run-stack.sh start
./scripts/run-stack.sh restart
./scripts/run-stack.sh stop
./scripts/run-stack.sh status
```

A130 可使用：

```bash
./scripts/run-stack.sh rebuild
```

8.62 禁止使用 `rebuild`。

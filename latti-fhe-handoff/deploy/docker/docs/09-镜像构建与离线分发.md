# 09-镜像构建与离线分发

本文用于 A130 构建镜像并分发到 8.62。

## A130 构建并验证

```bash
cd /home/wuwm/prod-project/latti-client/deploy/docker

./scripts/run-node.sh up -d --build
./scripts/run-node.sh ps
curl -fsS http://127.0.0.1:58996/api/v1/health
```

## A130 打包镜像

```bash
docker save redis:7-alpine latti/latti-server:latest -o latti-docker-images.tar
gzip -f latti-docker-images.tar
```

生成：

```text
/home/wuwm/prod-project/latti-client/deploy/docker/latti-docker-images.tar.gz
```

## 传到 8.62

从 A130 推送：

```bash
rsync -avh --progress \
  /home/wuwm/prod-project/latti-client/deploy/docker/latti-docker-images.tar.gz \
  jiangsy@192.168.8.62:/home/jiangsy/prod-project/latti-client/deploy/docker/
```

以下命令按 8.62 项目路径 `/home/jiangsy/prod-project/latti-client` 编写。

也可以在 8.62 主动拉取：

```bash
cd /home/jiangsy/prod-project/latti-client/deploy/docker

rsync -avh --progress \
  wuwm@192.168.3.130:/home/wuwm/prod-project/latti-client/deploy/docker/latti-docker-images.tar.gz \
  ./
```

## 8.62 导入镜像

```bash
cd /home/jiangsy/prod-project/latti-client/deploy/docker

docker load -i latti-docker-images.tar.gz

docker images | grep -E 'redis|latti-server'
```

## 8.62 重建容器

```bash
./scripts/run-node.sh up -d --force-recreate fhe-api fhe-worker
./scripts/run-node.sh ps
```

8.62 不执行 `--build`。

## 模型目录同步

镜像不包含 `third_party/latti-ai-runtime`。模型目录同步见 [03-运行时与模型目录准备](03-运行时与模型目录准备.md)。

# 08-日志与状态查看

## 查看容器状态

```bash
cd /home/wuwm/prod-project/latti-client/deploy/docker

./scripts/run-node.sh ps
```

直接查看 Docker：

```bash
docker ps --format 'table {{.Names}}\t{{.Status}}\t{{.Ports}}'
```

## API 日志

```bash
./scripts/run-node.sh logs -f fhe-api
```

## Worker 日志

```bash
./scripts/run-node.sh logs -f fhe-worker
```

## Redis 日志

```bash
./scripts/run-node.sh logs -f fhe-redis
```

## Nginx 日志

A130 和 8.62 使用统一日志文件名：

```bash
tail -f /tmp/latti-nginx-access.log
tail -f /tmp/latti-client-error.log
```

## 端口监听

```bash
ss -lntp | grep -E ':8995|:58996|:58998'
```

## 不跟随日志

去掉 `-f`：

```bash
./scripts/run-node.sh logs fhe-api
```

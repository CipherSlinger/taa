# 00-部署总览

## 当前架构

```text
客户端/调用方
  -> Host Nginx :8995
      -> /api/v1/health
          -> Node API :58996
      -> 业务接口
          -> 按 X-User-Id 一致性哈希
          -> Node API :58996
          -> Node Local Redis :58998
          -> Worker + GPU + FHE runtime
```

## 核心原则

1. 同一 `user_id` 必须稳定路由到同一 Node。
2. 每个 Node 使用自己的 Local Redis、本地 eval context、任务输入和结果目录。
3. Docker Compose 不管理 Nginx，Nginx 使用宿主机配置文件。
4. 当前不使用历史 Gateway / Route Redis 作为活跃部署组件。

## 服务和端口

| 服务 | 默认端口 | 说明 |
|---|---:|---|
| Host Nginx | `8995` | 对外入口，一致性哈希路由 |
| Node API | `58996` | FastAPI 服务 |
| Node Local Redis | `58998` | 当前 Node 任务、队列、事件和 GPU lease |

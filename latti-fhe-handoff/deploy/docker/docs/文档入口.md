# Docker 部署文档入口

当前服务端部署采用 **Host Nginx 按 `X-User-Id` 一致性哈希直连多 Node**：

```text
客户端/调用方 -> Host Nginx :8995 -> Node API :58996 -> Node Local Redis / Worker / GPU
```

## 环境定位

| 环境 | 机器 | 用途 | 构建策略 |
|---|---|---|---|
| 测试环境 | `192.168.3.130` / A130 | 测试、验证、构建镜像 | 允许 `--build` |
| 正式环境 | `192.168.8.62` | 正式服务 | 不在本机 build，只导入 A130 镜像 |
| 新增节点 | 其他 GPU 服务器 | 加入 Nginx 一致性哈希 | 可本机构建或导入 A130 镜像 |

## 维护原则

1. 每篇文档只负责一个阶段，不重复完整部署流程。
2. 8.62 正式环境不执行 `--build`。
3. 修改 Docker 配置后先运行 config 校验。
4. 修改 Nginx 配置后先运行 `nginx -t`。
5. 不提交 local env、运行数据、模型文件、镜像包、密文、eval context 和结果文件。

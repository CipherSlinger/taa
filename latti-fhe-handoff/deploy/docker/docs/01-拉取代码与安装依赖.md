# 01-拉取代码与安装依赖

## 拉取代码

```bash
cd /home/wuwm/prod-project

git clone -b feat/end-to-end https://github.com/cipherflow-fhe/latti-client.git

cd /home/wuwm/prod-project/latti-client
```

确认分支：

```bash
git branch --show-current
git log --oneline -5
```

## 安装基础依赖

Ubuntu：

```bash
sudo apt update
sudo apt install -y git curl rsync nginx docker.io docker-compose-plugin
sudo systemctl enable --now docker
```

检查版本：

```bash
docker version
docker compose version
nginx -v
```

## 检查 GPU

宿主机：

```bash
nvidia-smi
```

容器内：

```bash
docker run --rm --gpus all nvidia/cuda:12.2.0-base-ubuntu22.04 nvidia-smi
```

如果容器内 `nvidia-smi` 失败，需要先修复 Docker NVIDIA runtime。

## 进入部署目录

```bash
cd /home/wuwm/prod-project/latti-client/deploy/docker
```

其他服务器按实际项目路径进入 `latti-client/deploy/docker`。
